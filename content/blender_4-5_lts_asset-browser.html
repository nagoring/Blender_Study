アセットライブラリの仕組みと、ワークフローへの活用を簡単に紹介します。アセットブラウザーは、モデル、マテリアル、ブラシ、ジオメトリノードの設定、スクリプトなど、すべてのアセットを1か所にまとめて扱える便利なツールです。アセットブラウザーからドラッグするだけで、環境の飾り付けやマテリアルの適用が速くできます。「Cube Diorama」をダウンロードして展開し、試してみましょう(原文ページ参照)。

アセットブラウザーの基本

cube_diorama.blend を開きます(シェーダーのコンパイルで、読み込みに少しかかる)。左下が、さまざまなカタログ(家具、植物、額縁など、アセットのフォルダやコレクションのようなもの)を持つアセットブラウザーです。「Floor」カタログから、別のマテリアルを床にドラッグして割り当てられます。オブジェクトでも同じです。

アセットライブラリを追加する

  1. File › Preferences › File Paths(Ctrl + ,)で、+ を押して「cube_diorama」の場所へ移動。
  2. 3Dビューポートを分割して、小さいほうをアセットブラウザーにする。
  3. 現在のアセットライブラリを、「All Libraries」から「cube_diorama」に変更。同じマテリアルとオブジェクトのカタログが見える。

アセットのリンク

現在のファイルへのアセットの追加は、リンクまたはアペンドで行えます。Import Settings を「Link」にして、アセットを3Dビューポートにドラッグすると、データがリンクされます。アウトライナーで、オブジェクトの後ろにリンクのマークが付きます。オブジェクト自体が、コレクションではなくアセットとして「マーク」されているため、移動できません。オブジェクトをコレクションに入れると、コレクションがインスタンスとしてリンクされ、位置・回転・スケールを変えられます。

コレクションをリンクするには?

マークされたコレクションを作るため、cube_diorama.blend に戻ってアセットの1つをコレクションに入れ、「Mark as Asset」を選びます。「Unassigned」カタログから、アセットを Object › Decorations にドラッグして保存します(アスタリスクは、上部バーの .blend ファイルと同様に、未保存の変更を示す)。

次に、アセットを使いたい別のファイルを開き、Import Settings を「Link」にして3Dビューポートへドラッグすると、インスタンスになります。今度は Append にしてドラッグしてみましょう。Import Settings を Append にすると、オブジェクトを特定の位置に配置できますが、データはリンクされません。

アセットライブラリを作る

動画では、「cubes」と「cylinders」という2つのコレクションに、サブコレクション(アセットになるもの)があります。複数のコレクションを右クリック › Mark as Asset でマークできます。マテリアルのマークも同様です。Preferences の File Paths › Asset Libraries にアセットライブラリを追加し、新しいファイルで、Linked に設定したアセットを追加します。

まとめ

コレクションとマテリアルをアセットとしてマークする方法と、自分のアセットライブラリの作り方を学びました。
