スカルプトの基本を学び終えたので、デザインに色を付けます。スカルプトモードで直接頂点をペイントする方法を扱います。

頂点ペイントモードを使わない理由

Blenderには頂点カラーを塗るモードが2つあります。頂点ペイントモードは元々の専用モードで、次の特徴があります。

  • 頂点だけでなくフェイスコーナーを塗れるため、各頂点に鋭い境界を作れ、少ない頂点で細かな表現ができる
  • マスクの代わりに編集モードの選択を使う
  • 細かな制御の代償として、頂点数が多いと性能がずっと悪くなる

そのため、頂点ペイントモードは、ローポリのゲームアセットや、プロシージャルなジオメトリ/マテリアル用の頂点カラーに向きます。将来的には、より汎用的な「アトリビュートペイント」モードになる可能性があり、スカルプトモードは、ベースカラーのペイントに重点を置く方向です。スカルプトモードには、テクスチャ付きの「アーティスティック」なブラシも多くあります。

Multires は頂点カラー非対応

現状、Multires はカラーアトリビュートをサポートしません。スカルプトモードでは頂点を塗れず(Multires 付きのオブジェクトは黒く表示)、細分化後の結果には色を付けられません。ベース解像度にだけ色を付けられます。さらに詳しく塗るには、Multires を適用する必要があります。重要 コレクションを再度複製し、新しいファイルとして保存して、古いバージョンを残しておきましょう。UVマップにも同じ制限があり、Multires 付きのスカルプトモードではテクスチャを表示できません。

頂点を塗る

肌の色、クローバーの緑、服のいろいろな色など、ベースカラーで全体を塗ります。

  1. スカルプトモード(Ctrl + Tab)で、アセットシェルフの Paint カタログから Paint Hard ブラシを選び、塗ってみる。
  2. ツールバーでは、ブラシが種類別にまとまっています。「Brush」または「Paint」をクリックすると、その種類の最後に使ったブラシになり、スカルプトとペイントの切り替えが速くなります。右クリックで、特定のブラシではなく Paint ツールにショートカットを割り当てるのもおすすめです。
  3. ブラシを使うと、ビューポートのシェーディングが自動で変わります。シェーディング設定で Object Color が Attribute になっており、アクティブなカラーアトリビュートが表面の色として使われます。アクティブなカラーアトリビュートは、プロパティの Object Data タブ、またはスカルプトモード中のヘッダーで確認できます。ペイントブラシを使うと自動で作成されます。
  4. 複数のカラーアトリビュートは、マテリアルの別々の入力に使うなどの用途がありますが、2Dペイントソフトのレイヤーのスタックとは違います。今は、無視して問題ありません。

全体をまとめて塗るには、ツールバーの Color Filter で Filter Type を Fill にして、ビューポートをドラッグします。

ブラシの色は、ブラシ設定または右クリックメニューで変更します。便利なショートカット:X で第1色/第2色の入れ替え、Ctrl + 左クリックで第2色で塗る、Shift + X でカーソル下の色をスポイト。色の変化には、Paint Soft など他のブラシを使えます。

くぼみと縁の摩耗を塗る

陶器の彫刻は通常、1つの塊から成形されます。この見た目を再現するために、全オブジェクトを結合して仕上げます。

すべてを結合する

非常に破壊的な操作なので、古いバージョンを残してから行いましょう。

  1. すべてのオブジェクトを選択し、Ctrl + A › Visual Geometry to Mesh でモディファイアを適用。
  2. Ctrl + J で結合し、スカルプトモードで高い解像度(R)を設定して、リメッシュ(Ctrl + R)。
  3. 結合した境目を、Shift + 左クリックでスムーズにして、成形したような見た目にする。

リメッシュで頂点カラーが少し劣化します。新しい頂点が、元のメッシュの最も近い色を拾うため、ディテールが失われ、グラデーションがギザギザになります。ペイントブラシと Shift + 左クリックのぼかしで整えられます。

キャビティ・オートマスキング

1つに結合すると、くぼみを簡単に塗れます。ヘッダー(または Alt + A)で Cavity オートマスキングを有効にし、暗い色で塗ると、くぼみだけに効果が出ます。ストロークごとに再生成されるため、直感的に素早く使えます。ヘッダーで調整できる項目は次のとおりです。

  • Blur を 5 などにすると、より滑らか(数値が高いほど遅い)
  • Custom Curve で、どの曲率の面に効かせるかを調整

暗い色や彩度の高い色で色の変化を付けましょう。Cavity (Inverted) を使えば、くぼみではなく擦り減った縁を素早く塗れます。

EEVEE向けのクイックマテリアル

EEVEE(または Cycles)でレンダリングすると、見栄えが分かります。頂点カラーを使うマテリアルは、すぐに設定できます。

  1. オブジェクトを選び、プロパティの Material › New で新しいマテリアルを作成。
  2. Surface › Base Color の黄色い丸をクリックし、ドロップダウンから Color Attribute を選ぶ。

名前を指定しない場合は、アクティブなカラーアトリビュート(選択状態のもの)が使われます。Material Preview でのライティングは、ヘッダーのシェーディング設定で、HDRI やスライダーから調整できます。ソリッド表示でもレンダー表示でも、スカルプトとペイントを続けましょう。レンダー表示のほうが、色を調整しやすくなります。

まとめ

スカルプトモードのペイントブラシ、Color Filter、くぼみと摩耗のためのキャビティ・オートマスキング、EEVEE の利用を学びました。これでスカルプトの章は終わりです。さらに学ぶには、Blender マニュアルなどを参照してください。
