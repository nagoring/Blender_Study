はじめに

このコースは Blender 4.5 LTS を前提に作られています。まず公式サイトから 4.5 LTS をダウンロードしてインストールし、起動しましょう。(なお、5.2 でもおおむね互換ですが、一部の機能は UI が異なる場合があります。)

スプラッシュ画面

  • New File:用途別(ビデオ編集など)に設定済みの新規ファイルを開く。
  • Open:既存の .blend ファイルを開く。
  • Recover Last Session:直前に作業していたファイルを復元して開く。
  • Recent Files:最近使ったファイルの一覧。
  • Donate:開発への寄付ページ。
  • What's New:今のバージョンの新機能紹介ページ。

スプラッシュ画面以外の場所をクリックすると閉じて、作業を始められます。

環境設定を開く

左上のメニュー Edit › Preferences で設定ウィンドウが開きます。

Interface(インターフェース)

Resolution Scale で UI の大きさを変更できます。高解像度モニターや小さい画面では、見やすいサイズに調整してください。後からいつでも変更できます。

Input(入力)

  • 中ボタン(MMB)がない場合は、Alt などのキーで中ボタンをエミュレートできます。
  • ペンタブレットにも対応。筆圧を使えるためペイントやスカルプトが正確になり、手首にも楽です。一方でスクロールホイールがないため、一部の操作はやや遅くなります。

Keymap(キーマップ)

多くのソフトは左クリック(LMB)で選択しますが、Blender では右クリック(RMB)で選択する設定も選べます。選択と操作(移動など)を別のボタンに分けることで切り替えが速くなり、ウェイトペイントなどで特に効果的です。指の負担も分散されます。コースでは RMB を推奨していますが、どちらを使うかは好みです。

System(システム)

最上部の Cycles Render Devices で、レンダリングに使うハードウェアを選びます。

お使いのGPU選ぶ項目
NVIDIACUDA(互換性が高く安定、CPU負荷が軽い)または OptiX(レイトレーシング専用で高速)
AMDHIP(HIP RT でレイトレーシングも有効化可)
InteloneAPI
AppleMetal(MetalRT で高速化)

ハードウェアによっては GPU と CPU の両方を有効にすると性能が上がります。

設定の保存

設定が終わったら、Save Preferences を押して次回以降も保持されるようにします。

まとめ

快適に作業するための基本設定(UIの大きさ、入力、キーマップ、レンダーデバイス)を行いました。
