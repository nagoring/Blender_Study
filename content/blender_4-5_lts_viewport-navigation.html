ナビゲーションギズモ

  • ビューポート右上のギズモを左ドラッグするとビューを回転できます。軸の球にカーソルを合わせてクリックすると、その軸方向にビューが揃い、平行投影(Orthographic)になります(技術図面のように奥行きが消え、比率を確認しやすい)。
  • ギズモの下のボタン:虫眼鏡=ドラッグでズーム、手のひら=パン(平面移動)、カメラ=シーンのカメラとの切り替え、グリッド=透視投影/平行投影の切り替え。
  • 左上に現在のビュー名が常に表示されます。

マウスとキーでの高速ナビゲーション

3ボタンマウス(左・右・中=ホイール押し込み)を前提にします。ペンタブレットは、サイドボタンとペン先の押し込みで代用できます。

操作動作
MMB ドラッグオービット(回転)
Ctrl + MMB 上下ドラッグ / ホイールズーム
Shift + MMB ドラッグパン
テンキー 1 / 3 / 7フロント / 右 / トップビュー
Ctrl + テンキー 1 / 3 / 7反対側(バック / 左 / ボトム)
テンキー 2・4・6・815度刻みで回転
テンキー 5透視 / 平行投影の切り替え
テンキー +/-ズーム
` (バッククォート)ビュー切り替えのパイメニュー(テンキーがない場合に便利)
Tip MMBで回転しながら Alt を押すと、45度刻みでビューが揃います。

その他のナビゲーション

  • テンキー .:選択物にフレームを合わせる(Frame Selected)
  • Shift + B:ドラッグで囲んだ範囲にズーム(Zoom Region)

まとめ

ギズモ、マウス、テンキーの3通りの方法でビューを操作できるようになりました。覚えることが多いので、実際に何度も試して慣れましょう。
