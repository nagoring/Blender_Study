便利なコンポジットノードとテクニックを紹介します。コンポジットと密接に関わる、レンダリングの可視性も扱います。

ビューレイヤーを追加する

Cycles を使います。前のセクションと同じファイルを開き、View Layer › New で新しいビューレイヤーを追加します(すべてのコレクションが再び有効になります)。「lights_landscape、fx、landscape、shadow_casters」のコレクションを無効にします。

  1. 「spheres」という新しいコレクションを追加。
  2. Subdivision Surface(2〜3)の立方体を追加し、モディファイアを適用して、編集モードで To Sphere(Shift + Alt + S)。名前を「GEO-sphere-green」に。
  3. 緑の光を放つ新しいマテリアルを追加。
  4. 球を複製し、マテリアル欄の「2」をクリックして「ユニーク」なマテリアル「Orange」にする。Base Color と Emission Color をオレンジにする。マテリアルとオブジェクトの名前を、適切に変更。

ビューレイヤーでの可視性

  • Object Properties › Visibility › Ray Visibility を開く。球の1つで「Camera」を無効にすると、カメラからは「見えなく」なるが、反射と影には影響する。「Shadow」を無効にすると、影への影響がなくなる。
  • 「sphere」コレクションの View Layer › Set Indirect Only:すべてのオブジェクトが、環境に間接的に影響します(今回は、反射、発光、影)。
  • Ray Visibility のトグルを試して、環境への影響を確認しましょう。
  1. Render Settings の Film タブで Transparent を有効にする。World の背景がアルファチャンネルとして動作する。
  2. 「spheres」ビューレイヤーで、「spheres」コレクション以外をすべて無効にする。
  3. landscape ビューレイヤーで「spheres」コレクションを無効にする。
  4. 最後に、「building」コレクションで「spheres」に View Layer › Set Indirect Only を設定する。
レンダリングの前に、Landscape ビューレイヤーで Environment を有効にして、青空をコンポジットに戻しましょう。
警告 複数のビューレイヤーがあるときに新しいコレクションを追加すると、新しいコレクションが、各ビューレイヤーで有効になります。

コンポジターでの作業

  1. レンダリング後、Compositor ワークスペースで、下ではなく上のノードツリーを使う。landscape ビューレイヤーでは背景がなくなっている。
  2. Alpha Over ノードを追加し、Env を上のソケット、Image を下のソケットにつなぎ、結果をプレビュー。
  3. スペースを空けて、landscape の Render Layer ノードを複製し、リストから spheres を選ぶ。Alpha Over を複製して、spheres の Render Layer と、最後の Add ノードをつなぐ。

別のビューレイヤーを使ったおかげで、球とそれ以外の Render Layer を独立に調整できます。より簡単な方法は Cryptomatte です。利用できるコンポジットノードを見てみましょう(一部は、ここでは扱いません)。

入力(Input)ノード

画像、動画、連番画像などのデータを Blender に取り込みます。

重要な色調整ノード

  • Gamma / Exposure:カラーマネジメントに似た調整。
  • RGB Curves:カーブに基づいて、色と値に影響する。コントラストを増したり、色を変えたりできる。
  • Color Balance:シャドウ、ミッドトーン、ハイライトの範囲ごとに、色と値に影響する。

重要なフィルターノード

2Dのデジタル編集ソフトのフィルターに似ています。

  • Blur ノード:最も人気のブラーノードは、複数のアルゴリズム(方法)を持つ。計算が速いものも、正確だが遅いものもある。
  • Glare ノード:ブルーム、グレア、フレアなどを追加し、レンズに光が当たる効果を再現する。
  • Denoise ノード:すでに説明したとおり、きれいな画像を作るのに非常に価値がある(以前は難しかった)。

重要なマスクノード

画像の一部を選ぶようなもので、他のノードをどう適用するかを決めるのに欠かせません。

  • Cryptomatte:View Layer で有効にする必要がある。オブジェクト、マテリアル、アセットに基づいてマスクを作れる。
  • Box Mask / Ellipse Mask:パラメーターまたはウィジェットで、「パラメトリックに」マスクを作る。Ellipse Mask は、特にビネットの作成に便利。

これらのノードを、作業中のコンポジターに追加して試してみましょう。
