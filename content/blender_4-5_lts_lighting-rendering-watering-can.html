小さなセットを作り、ライトを加えて、じょうろをきれいに見せます。このままアニメーションをレンダリングしても、コンポジットの章まで待って、ポストプロセスを加えて再度レンダリングしても構いません。

フォトスタジオを作る

  1. 新規ファイルで立方体を削除し、平面を追加して、「Back」の辺を3m 上に押し出す。ベベルで、なめらかなランプ状にします(「リンボ」背景)。編集モードでリンボ背景をスケールして、作業スペースを広げる。
  2. 好きな形の展示台(ペデスタル)を作る(Bevel モディファイアを追加)。主役はじょうろなので、展示台が目立ちすぎないように。オブジェクトには「GEO-」の接頭辞を付ける。
  3. リンボ背景と展示台に、簡単なマテリアルを付ける。リンボ背景は反射させすぎず、マット(艶消し)にする。マテリアルは後で調整します。

リンクとアペンド

別の .blend ファイルにオブジェクトを追加するには、データブロックをリンクまたはアペンドします。オブジェクト、コレクション、ノードツリー、テクスチャなど、ほぼ何でも、別の .blend から持ってこられます。

  • リンク:データ(データブロック)を特定の Blender ファイルから参照として読み込む。watering_can.blend で変更すると、ファイルを開き直す(更新する)と、他のファイルにも反映される。
  • アペンド:データがつながっていない状態のインポートに近い。watering_can.blend の変更は、他のファイルに反映されない。

このコースでは、変更が反映されるようリンクを使います。File › Link(または F4)で、watering_can.blend の場所へ移動し、Collection › watering_can を選ぶと、最初はインスタンスが作られます。必要なら、展示台やリンボ背景を調整します。データの扱いはプロジェクトワークフローの章で扱います。

警告 watering_can コレクションに他のオブジェクトを入れていないことが前提です。入れた場合は、コレクションの外に移動し、ファイルを保存して、作業中のファイルを再読み込み(先に保存)します。何も見えない場合は、構築エフェクトのアニメーションを再生してください。

ライブラリオーバーライド

リンクしたままでは、このように編集できないため、構築エフェクトのモディファイアを調整するには、まずライブラリオーバーライドを追加します。アウトライナーでじょうろのコレクションを選び、右クリック › Library Override › Selected(より「深い」レベルでオーバーライドするため、2回行う)。ライブラリオーバーライドで、リンクしたデータの特定の部分を編集でき、柔軟性が増します。

じょうろが元の位置に戻ります。これは、オーバーライドされた状態で、データブロック(オブジェクトやコレクションなど)がリンクされていることを意味します。モディファイアやメッシュのデータなどはリンクのままなので、元のファイルでの変更は、現在のファイルに反映されます。

(任意)キーフレームを削除するには、Object Properties の Action データを削除します。

レンダリングの準備

  • Cycles と GPU レンダリングに切り替える。
  • ビューを水平に分割し、一方をカメラ用、もう一方を作業用の3Dビューポートにする。
  • カメラを追加し、Super Analog 35 のプリセットを使う。解像度を 2048 × 858 に。
  • 「sets」「lights」「cameras」の3つのコレクションを作り、該当のオブジェクトを入れる。
  • Color Management の View Transform を Filmic に。

ライトを追加する

ライトを追加して、World の色を調整します。自由に追加しても、動画の手順を参考にしても構いません。シェーディングやテクスチャが気に入らなければ、watering_can.blend に戻って調整しましょう(この例では、粗さが「シミ」を作りすぎて目立ったため、粗さのテクスチャを調整しました)。Color Management の設定を試し、展示台が目立ちすぎないようにします。リンボ背景に、控えめな色を付けてもよいです。

テストレンダリング

このあたりで、静止画のレンダリングを作って、ノイズの量を確認するとよいでしょう(動画の例では、デノイズ付き 1024 サンプルで、きれいな結果)。レンダーウィンドウ(F11)のレンダースロットで、画像を比較し、そのセッションで作ったレンダリングを確認できます(実体は、View に設定した画像エディター)。

警告 既定では、レンダリングするたびに画像は自動保存されません。
  1. View Layer タブで Glossy Direct を有効にする。
  2. Render Settings で Max Samples を 12 にして、F12 でレンダリング。スロットを Slot 2 に変えて、Max Samples を 128 にする。
  3. レンダリング中、左から右へ、現在のフレーム、直前の画像のレンダリング時間、現在の経過時間、残りの推定時間、メモリ使用量、シーンとビューレイヤーの名前、現在のサンプル数が表示されます。
  4. F11 でレンダーを表示し、別のスロットを選ぶ。J で次のスロット、Alt + J で前のスロットへ。パスを Glossy Direct(GlossDir)に切り替えて比較。Noisy Image でも比較できる。ノイズのレベルを比較して、最終レンダリングの品質を決めるのに適している。スロットは最大8個で、Blender を閉じるとデータは消える。

レンダリングを準備する

  • ライティングに満足したら、タイムラインでフレーム範囲を設定(ここでは 80。構築済みのじょうろを見せるために、10〜20フレーム余分に含む)。
  • Output Properties で File Format を「FFmpeg Video」に、Container を「MPEG-4」に、Output Quality を「High Quality」に。出力パスと「watering_can_construction_test_01.mp4」のような名前を設定。
  • Ctrl + F12 でアニメーションをレンダリング。

この節で使ったファイル(watering_can_presentation.blend、CC-BY)は、原文ページからダウンロードできます。この章はここまでで、コンポジットの章でもじょうろを続けます。

まとめ

別のコレクションを現在の .blend にリンクする方法、ファイル間でデータをリンクしつつ一部を編集できるライブラリオーバーライド、スロットでレンダリングを繰り返し比較する方法を学びました。
