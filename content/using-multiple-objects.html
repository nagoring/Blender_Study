複雑な形を作るための、複数オブジェクトを使うスカルプトを学びます。ここからは庭のノーム(小人の置物)を作り、以降のレッスンでも続けます。例と同じ形にする必要はなく、リファレンスを探して自分なりに作ってください。内容は次のとおりです。

  • ディテールの前に大きな形を作る「ブロッキング」
  • スカルプト用ベースメッシュの作り方
  • 複数オブジェクトでのスカルプト
  • モディファイアを使ったスカルプト

ノームのブロッキング

まず基本形でおおまかな比率を作る「ブロックアウト」を行います。全体を見る前にディテールを作り込みすぎるのを防げます。Shift + A でプリミティブを追加し、移動・回転・拡大縮小して体と頭の形を作ります(複製は Shift + D)。仮の形なので後で整えます。

Tip スカルプトの始め方は無数にあります。どのプリミティブやブラシを使うかは自由で、感覚に合うものを選んでください。

非破壊のミラー

  1. 脚のオブジェクトを選び、Mirror モディファイアを追加。
  2. Mirror Object のスポイトで、体や帽子など中心にあるオブジェクトを指定。
  3. 多用するなら「Center」という名前の Empty を作って基準にすると、胴体などより変更・置換されにくく安全です。
  4. 他のオブジェクトにコピーするには、対象をすべて選び、モディファイア付きのものを最後に(アクティブに)選んで、モディファイアのポップオーバーで Copy to Selected。
  5. または Ctrl + L › Copy Modifiers。選択物のモディファイアスタックを、アクティブなものの完全なコピーに置き換えます。

ベースメッシュのモデリング

プリミティブに合わない部分(帽子など)は、前章のモデリングツールで素早く作ります。このようなスカルプト用の事前モデルをベースメッシュと呼びます。

  1. 円錐を追加。頂点数 12、Base Fill Type は None。
  2. Subdivision Surface を追加し、厚み用に Solidify も追加。Ctrl + A でスケールを適用(厚みに影響)。
  3. 編集モードで先端の頂点を Ctrl + Shift + B でベベルしてリングを増やし、上の面を押し出して帽子の長い先端を作る。下のリングを押し出してつばを作る。
  4. Subdivision Surface を適用して解像度を上げ、スカルプトモードで Grab と Smooth で整える。大きな変更は大きい半径、仕上げは小さい半径で。
重要 オブジェクトモードでスケールを変えると、多くの機能が正しく動作しなくなります(スカルプトモードに入るとステータスバーに警告、ブラシカーソルもスケールされる)。Ctrl + A › Apply Scale をこまめに行いましょう。

トリムツール

靴は球から始めますが、下半分は編集モードで削除せず、Trim ツールを使います。球を追加し、スカルプトモード(Ctrl + Tab)でツールバーの Trim(またはヘッダーの Sculpt › Trim/Add › Box Trim)で下半分を切り落とします。ツールをクリックしたままドラッグすると、別の形(Polygon Trim など)に変更でき、靴底の側面を切り取れます。その後、平行投影のビュー(` メニューまたはテンキー 1/3/7)から、Grab(2D)ブラシでシルエットを整えます(X Mirror を有効に)。平行投影にならない場合は、テンキー 5 かギズモのグリッドアイコンを使います。

オブジェクトの切り替え

複数オブジェクトの間で、オブジェクトモードに戻って選び直すのは面倒です。別のオブジェクトにカーソルを合わせて Alt + Q を押すと、そのオブジェクトに切り替わり、オレンジに点滅します(どのモードでも、Grease Pencil やカーブでも有効)。アウトライナーのモードアイコンからも可能です。胴体・腕・脚を Grab、Draw、Scrape、Smooth で少し整えます。この段階では、リメッシュの解像度を上げすぎないようにしましょう。

Skin モディファイアでベースメッシュを作る

立方体に Skin モディファイアを追加すると、頂点と辺が、伸びの少ない四角形トポロジーのチューブになります(元の面は破棄される)。スカルプトや後の細分化に最適です。

  • 編集モードで X線(Alt + Z)を有効にし、不透明度を 1.0 にすると、内側のワイヤーが見えます。
  • ひげの束:全頂点を M › At Center でまとめ、E で何度も押し出して曲線を作り、Ctrl + A で頂点の太さを変えて先細りに。
  • 滑らかにするため、Skin の上下に Subdivision Surface を1つずつ(上は辺を滑らかな曲線に、下はチューブを丸く)。Mirror も加えて片側だけの作業に。
  • 編集モードで束を複製して増やします。全体の形で十分で、ディテールは不要です。
  • Tip 束全体の選択は Ctrl + L(Select Linked)、カーソル下だけなら L(誤選択に注意)。
  • 複製した部分が Skin で何も生成されない場合:接続された頂点の1つが「ルート」(赤い点線の輪)です。複製でルートを含めなかった場合は、端点の頂点を選んで Skin の Mark Root を押します。
  • 左右非対称にするには、中心に近い束を P › Selection で別オブジェクトにし、Alt + Q で切り替えて Mirror を外し、束を足します。

粗いベースメッシュ:手

手は、クリーンなトポロジーが後で役立つので、ボックスモデリングで素早く作ります。立方体を平らにスケールし、幅方向と高さ方向に Ctrl + R でループを2本ずつ入れ、指、親指、手首を押し出し、指先を動かして広げ、伸びた四角形が減るようループを追加、Subdivision Surface を追加して適用します。重要なのは最終的な形ではなくクリーンなトポロジーです。形は次のレッスンでスカルプトします。

さらに非対称に

  1. 腕と手の Mirror モディファイアを外す。
  2. Transform Pivot Point を 3D Cursor に。
  3. 腕と手を選び、Shift + D で複製して右クリックで移動をキャンセル。
  4. Ctrl + M › X でミラー反転。
  5. そのあと Ctrl + A › Scale でスケールを適用(適用しないと、ツールやブラシも反転する)。
  6. 編集モードで全選択し、Shift + N で法線を再計算(面が裏返らないように)。

これで、もう片方の腕を別のポーズにして、一方の腕を差し出せます。

ミニ課題

ノームが手に持つ小物(花やクローバー)を、Skin モディファイア、ボックスモデリング、スカルプトのいずれかで作ってみましょう。

まとめ

プリミティブ追加、オブジェクトの高速切り替え、スケール適用の重要性、オブジェクト全体のミラー、ボックスモデリングと Skin モディファイアによるベースメッシュ作成を学びました。
