この章ではコンストレイントを使って、Sky をアニメーションしやすくする制御システムを作ります(練習用:sky_03_weights.blend、原文ページ参照)。

最初のコンストレイント

コンストレイントは、ボーン間の変形のルールを作ります。

  1. ポーズモードで、スカーフの先端 Scarf3 を選ぶ。
  2. Bone Constraints タブ(Object Constraints と混同しない)で Add Bone Constraint › Copy Rotation。
  3. Target に RIG-Sky(スポイトが便利)、Bone に最初のスカーフのボーン Scarf1 を指定。

コンストレイントされたボーンは緑色になり、ターゲットの回転を完全にコピーします。ただし、最初や中間のボーンを回しても、先端は最初のボーンの回転を厳密にコピーするだけで、あまり役に立ちません。また、先端のボーン自体を回せなくなります。なお、ここではボーンコンストレイントを扱いますが、オブジェクトコンストレイントも、オブジェクト間で同様に変形の関係を作ります。

コンストレイントの設定

数学を使わない説明です。

  • Mix Mode:変形の組み合わせ方。Before Original にすると、(仮想の)親ボーンにコンストレイントがあるように動くので、コンストレイントがあってもボーンを回せます。
  • Target / Owner Space:ワールド空間でコピーすることは、ターゲットに直接くっつけるのと同じです。ローカル空間でコピーすることは、ターゲットの動きを繰り返すことに似ています。ここでは、スカーフの先端に、根本の動きを繰り返させたいのでローカル空間にします。

設定したコンストレイントは、中間のボーンにもコピーできます。中間のボーンを先に選び、先端のボーンを最後に(アクティブに)選んで、Pose › Constraints › Copy Constraints to Selected Bones。Scarf1 を回すと、残りがカールしつつ、各ボーンを個別にもポーズできます。この知識だけでも、Copy 系、Limit 系、そして Damped Track(本来は「Aim コンストレイント」と呼ぶべきもの)が使えます。

ほかの便利なコンストレイント

  • Armature:ボーンを複数のボーンの子にできる。通常のペアレントとは併用せず、可能なら Child Of の代わりに使う。
  • Action:事前にキーフレームを打った任意のポーズへ、リグをブレンドできる(例:1つのコントロールで笑顔のポーズにする)。面倒な Transformation コンストレイントの代わりになることが多い。
  • Shrinkwrap:ボーンをメッシュ表面にスナップする(例:まぶたのボーンを眼球の表面に保つ)。
  • Stretch To:その名のとおり。スクワッシュ&ストレッチに必須。

インバースキネマティクス(IK)

「キネシス」はギリシャ語で「動き」、「インバース」はロボット工学に由来します。ロボットアームが90度回転したときの先端の位置を求めるのは簡単ですが、目標点に届く回転量と軸を求める問題は、その逆です。人間の腕や脚は(ときどき)そのように動きます。ほぼすべてのキャラクターに最低限必要な制御が、腕と脚の IK です。アニメーターが Hand.L を動かすと、Upperarm.L と Forearm.L が自動で必要な量だけ回転して、Hand.L が目的の位置に届きます。

Forearm.L に Inverse Kinematics コンストレイントを追加し、ターゲットボーンを Hand.L にしてみましょう。動かしても回転するだけで、望む動きになりません。編集モードで Alt + P(Disconnect)して Hand.L を切り離すと、全身が魚のようにバタバタし、ちらつきます。次の落とし穴があります。

落とし穴1:チェーンの長さ

Chain Length は既定で0で、これは「無限」と解釈されるため、IK のチェーンが背骨まで続いています。2 にして、Forearm.L と Upperarm.L だけにします。

落とし穴2:依存関係の循環

Forearm.L は IK コンストレイントで Hand.L に依存しますが、Hand.L はペアレントで Forearm.L に依存します。互いに依存しています(Dependency Cycle)。このため、ボーンが猛烈に回ったり、ポーズの方向が思うようにならなかったりします。今回の解決策は、Hand.L を Spine1 にペアレントすることです。

ポーズ中にボーンが1フレーム遅れる、ちらつく、制御不能に回るなどの動作は、依存関係の循環のサインです。ボーンを自分の子にコンストレイントすれば簡単にできてしまい、うっかり起きることもあります。原因の調査には、Blender のターミナルウィンドウ(警告やエラーの出力先)が役立ちます。ただし、バグのため、今回の IK の依存関係の循環は、ターミナルに警告が出ません。

落とし穴3:IK ポールターゲット

Hand.L をキャラクターに近づけると、肘が下、前、またはどこにも曲がらないことがあります。IK チェーンが縮むとき、すでに曲がっている方向(レストポーズで決まる)へ曲がり続けるためです。このチェーンは、床の方向に少し曲がっています。レストポーズを調整して、肘が後ろへ少し曲がるようにする必要があります。場合によっては、キャラクターのメッシュの調整が必要です。

落とし穴4:肘の向き

Hand.L を上下に動かすと、肘の向きが大きく変わります。アニメーターが打ち消すのは大変です。解決策は IK コンストレイントの Pole Target です。肘のすぐ後ろに「Arm IK Pole.L」を作り、Pole Target に指定します。まだ理想的ではありませんが、肘の向きは一貫します。

落とし穴5:ボーンのロール

ボーンのロールが動画と約180度違うと、この問題は目立たないかもしれません。それでも、ポーズモードと編集モードでボーンに違いが出るはずです(理想は、あってはなりません)。大きくても小さくても、修正は同じで、ボーンのチェーンを Arm IK Pole.L に完全に合わせます。

  1. ポーズモードで Arm IK Pole.L を選び、Shift + S › Cursor to Selected。
  2. 編集モードでボーンのチェーンを選び、Shift + N › Cursor で、ボーンのロールを3Dカーソルに揃える。
  3. ちょうど90度ずれるので、Ctrl + R で 90 を入力して補正する。

完璧な IK チェーンは、編集モードとポーズモードを切り替えても、ボーンがまったく動きません。ほかのコンストレイントで、ここまで厄介なものはありません。

IK をオフにする

キャラクターが歩いて腕を振るアニメーションでは、IK なしのほうが、きれいな弧を描きやすくなります。アニメーターは使い分けを知っている必要があり、リガーは両方の選択肢を用意する必要があります。IK コンストレイントを無効にするだけのはずですが、Hand.L を Forearm.L から切り離したままです。そこで、別の IK 用コントロールを作ります。

  1. Hand.L を複製し、「IK Hand.L」に改名。Deform のチェックを外す(重要)。
  2. IK コンストレイントの Subtarget を、新しい IK Hand.L に変更。
  3. Hand.L を再び Forearm.L にペアレント。
重要:Deform 変形しないボーンの Deform のチェックを外し忘れると、ウェイトペイントやオートマチックウェイトで、意図しないウェイトが付きます。IK Hand.L と Arm IK Pole.L も、Deform をオフにします。

FK モードは動作しますが、IK の手が制御できないほど回ります。ワールド空間の変形をコピーするのは、くっつけることに似ていると学びました。ここでは Hand.L を IK Hand.L にくっつけたいのです。プロパティエディターを使わず、Ctrl + Shift + C でもコンストレイントを作れます。IK Hand.L(ターゲット)を選び、Hand.L(オーナー)を選んで、Ctrl + Shift + C › Copy Rotation(既定の設定のまま)。両方のコンストレイントを切り替えて、IK と FK を切り替えられます(後で、もっと楽にする方法を学びます)。

練習

右腕と両脚を、同じ設定で自分で作りましょう。右腕は、Symmetrize で一度に作れます。

仕上げ:ルートボーン

IK の手や足を追従させずに Spine1 を動かすには、Root コントロールが必要です。床の上に作り、Spine1 とすべての IK コントロールをその子にします。膝の IK ポールは、足の IK コントロールの子にしても構いません。完成ファイル:sky_04_constraints.blend(原文ページ参照)。

まとめ

コンストレイントとは何か、Copy/Limit などの基本的な設定、起こりうる問題を含めた「完璧な IK チェーン」の作り方、IK をオフにして FK のポーズに戻せるようにする方法を学びました。
