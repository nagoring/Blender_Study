クラッシュなどでデータを失った場合に備えた、復元・バックアップの方法です。

データを守る方法

  • Recover Last Session(直前のセッションの復元)
  • オートセーブ
  • データ復旧機能を有効にした自分のサーバー/マシン
  • クラウドサービス(追加の安全策)
  • SVNリポジトリ(サーバー)

Recover Last Session

File › Recover › Last Session。保存していなくても、直前のセッションを復元できる場合があります。

オートセーブ

  • 初期設定では2分ごとに一時保存されます。間隔は Preferences › Save & Load › Blend Files で変更できます。
  • File › Recover › Auto Save... で /tmp/ 内の「_autosave.blend」ファイル一覧が開きます。
  • /tmp/ は再起動で消える場合があります。確実に残したいなら Preferences › File Paths › Temporary Files で保存先を指定します。

まとめ

復元には Recover Last Session とオートセーブを使います。自分のサーバーやクラウドを併用すると、さらに安全です。
