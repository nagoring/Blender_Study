解像度、アスペクト比、フレーム範囲、ファイル形式などに影響する、Output プロパティを見ていきます。カメラ設定のセクションと同じファイルを使います。

Format(形式)

Output プロパティには、Blender からデータを書き出すときの設定があります。Format は、アスペクト比と解像度を制御します。

  • X と Y のピクセル解像度を変えると、アスペクト比も変わります。プリセットから解像度を選べます。
  • Resolution Scale は最終的な解像度に影響します。200% 以上にして、2倍の解像度でレンダリングすることもできます。
  • Aspect は、正方形でないピクセル比の古いテレビに表示する場合以外は、ほとんど使いません。他の Format の項目はマニュアルを参照。

フレーム範囲

アニメーション用のフレーム/時間の設定です。Start/End は、タイムラインエディターと Frame Range タブの両方で変更できます。

Output(出力)

.jpg、.png、.EXR、.mp4 などの一般的なファイル形式でデータを書き出せます。

  • 画像をレンダリングして Image › Save as(Shift + Alt + S)を開くと、Output の設定に似た項目があります。File Format を変えると、名前欄にも反映されます(.mp4 コンテナの FFmpeg などを除く)。ファイル名だけ入力すれば、自動でファイル形式が末尾に付きます。
  • 画像形式ではなく動画形式にするには FFmpeg を選び、Encoding タブを開きます。1フレームをレンダリングするだけでは動画は書き出されず、Render Animation(Ctrl + F12)のときだけです。
警告 アニメーションを .mp4 などの動画ファイルに直接レンダリングすると、Blender がクラッシュしたときに失敗することがあります。.mp4 は完全にエンコードされないと正しく動作しませんが、連番画像のレンダリングには、この問題がありません。

他のタブ:Stereoscopy、Metadata、Post Processing も確認しましょう。

ミニ課題

原文のアニメーションに似たものを、正しくレンダリングします。

  • レンダー解像度を 2048 × 858 に正しく設定する。
  • ライティングを追加する。
  • カラーマネジメントで色とコントラストを調整する。
  • カメラを追加して、被写界深度を試す。
  • 30 fps で、.mp4 コンテナ、High Quality で書き出す。
  • レンダリングに時間がかかりすぎる場合は、サンプル数や解像度を下げる。ショットを最適化するほかの方法も探す。

アニメーションをレンダリングできれば、芸術的な調整は自由です。練習用ファイルと解答例(CC-BY)は、原文ページからダウンロードできます。次のセクションでは、じょうろのライティングとレンダリングを始めます。
