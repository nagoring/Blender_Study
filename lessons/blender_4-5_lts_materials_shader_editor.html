マテリアルとシェーダーエディター

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Materials & Shader Editor

サンプルファイルを使って、さまざまなマテリアルとノードを変更・追加します。Nicole Morena 作の「Cozy Kitchen」(Blender Demo Files のページからダウンロード、「blender-3.5-splash」)を使います。

テクスチャの再利用

ファイルを開き、Shading ワークスペースを作ります。3Dビューポートで、シーンのシェーダーがコンパイルされるのが見えます(Material Preview のため)。

なぜ EEVEE のシェーダーがコンパイルされる? 新しいファイルを開いて Material Preview に入るたびに起きます。自分のシーンでは、マテリアルを作業するときに行われます。グラフィックドライバーを更新した後は、再コンパイルが必要です。かかる時間は、複雑さ、シェーダーの数、ハードウェアによって決まります。

Rendered ビューに切り替えます。多くのオブジェクトに、さまざまなマテリアルがあります。テーブルクロスの柄を、椅子に付けてみましょう。

  1. テーブルクロスを選ぶと、「Tablecloth.png」というテクスチャの Image ノードがあります。椅子を選び、シェーダーエディターで Shift + A › Image Texture を追加し、画像のファイルアイコンから「Tablecloth.png」を選び、Base Color につなぎます。
  2. 柄がおかしいのは、テクスチャを正しくマッピングする Vector の入力ノードがないためです。Texture Coordinate ノードを追加し、Object ソケットを Vector ソケットにつなぎます。
  3. それでも解決しないときは、Projection Method を Box に変更します(「トライプラナーマッピング」。画像を箱のようにあらゆる面から投影する、簡単で素早い方法)。Blend の係数で、鋭いエッジをなくせます。
  4. テクスチャを小さくするには、Vector Math ノードを使います(「Vector Scale」で検索すると、Scale が設定された状態で追加されます)。Texture Coordinate と Image Texture の間につなぎ、Scale を 0.4 などにします。
  5. 色を変えるには、Image Texture と Principled BSDF の間に Color Ramp ノードを置きます。Base Color への接続を外し、Base Color から黒の色へ左ドラッグして色をドラッグし、再接続します。「ストップ」を左クリックして選ぶかドラッグして動かし、選んで色を変えられます。Ctrl + 左クリックで色のストップを追加できます。

木の床の調整

木の床板がどう作られているか見てみましょう。まず「CAM-wide」を選んで被写界深度を無効にします(レンダリングが速くなり、シェーディングの変更結果が見やすくなる)。床板のオブジェクトを選んで、ノードの構成を確認します。色のストップを調整して、3Dビューポートで結果を確認しましょう。

このノード構成で木を作る仕組み

左から右へ、最初の4つのノードは次のとおりです。

  • Generated 座標を使う。
  • Mapping ノード:テクスチャのマッピングを調整(ここでは、スケールを調整して引き伸ばしている)。
  • Vector に別のテクスチャ(ここでは Noise Texture)で影響を与える、やや変わった方法。
  • 最後の Noise Texture。

最後の Noise Texture の後の3つのノードは、同じデータを別々に加工します。

  • 上の Color Ramp:色に影響する。
  • もう1つの Color Ramp:Roughness に影響する。ストップを動かすと、木の床の粗さ(光沢)が変わる。色情報を含まないよう、白と黒だけを使う。
  • Bump ノード:Noise Texture の値をノーマルとして解釈する。

2つの Noise Texture の各スライダーを動かして、レンダリング結果への影響を確認しましょう。Render Settings で Viewport Denoise を無効にすると、結果が速く見やすくなる場合があります。

光の効果を追加する

左の2つのランプに、光の効果を追加します。

  1. Material Preview に切り替え(読み込みに数秒かかる)、ランプを選んでカーソルをスナップし、Mesh › Circle を追加して、ランプの内側に収まるようスケールダウン。選択を下へ押し出して少し拡大し、円錐の形にモデリング。
  2. 新しいマテリアル「light_effect」を作る。
  3. Texture Coordinate を追加し、Generated ソケットから Separate XYZ を追加。Z 出力をプレビューすると、上から下へのグラデーションが見えます。
  4. Color Ramp を追加して Alpha につなぐ。Color Ramp を選び、Ctrl + Shift + D で、接続を保ったまま複製し、上に移動する。これが Base Color になる。色を暖かく居心地のよい色にする。白のストップの値を下げると、オブジェクト全体がより透明になる。
  5. 上の Color Ramp の Color 出力を、Emission Color にもつなぎ、Emission を 1 にする。オブジェクトが、弱い光を放つようになる。設定を調整し、もう1つのランプにも複製する。

Tip Material Preview と Rendered を切り替えると、シェーディングの変更を素早くプレビューし、Rendered で「最終的な」結果を確認できます。マテリアルの複雑さによっては、Rendered のままのほうが速い場合もあります。

ミニ課題:カボチャ

左上のカボチャに、原文の法線の結果を作ります。カボチャの各セグメントを同じ方法でUV展開する必要があります。Texture Coordinate、Mapping、Noise Texture、Bump のノードを使います。ヒント:Mapping の Scale を変えるとノイズを引き伸ばせ、Noise Texture のパラメーターを調整するとディテールが増え、Bump の Strength を下げて Distance を上げます。

まとめ

Texture Coordinate ノードと Image Texture の投影方法の組み合わせ、Color Ramp での色の再マッピング、Separate XYZ でのベクトルの分離、テクスチャのデータを色、粗さ、法線など別の用途に分けて使う方法を学びました。シーンのマテリアルを、変更・調整・作成して試してみましょう。
