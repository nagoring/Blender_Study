単一オブジェクトの細かな制御

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Fine Control on a Single Object

🎬 このレッスンの動画は原文ページで視聴できます。 原文ページを開く(動画付き)
このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

前のレッスンのノームのブロッキングを続け、オブジェクトを結合して形を整えます。形を制御するために、次の新しい概念を学びます。

  • マスクとフェイスセットによる、メッシュの部分的なスカルプトと非表示
  • それらの直感的な作成と編集
  • スカルプトモードでの移動・回転・拡大縮小

バージョンを残す

古いバージョンの復元が必要になったり、ファイルが壊れたりする場合に備えて、番号付きの .blend を定期的に保存しましょう。同じファイル内で、スカルプトの途中経過をコレクションとして複製して残すのも便利です。Tip オブジェクトモードで数字キーを押すと、コレクションを即座に切り替えられ(比較に最適)、Shift + 数字キーで追加/削除になります。アウトライナーで目のアイコンを Ctrl + クリックしても、そのコレクションだけを表示できます。

ノームの結合と整形

腕を選び、胴体を最後に(アクティブに)選んで Ctrl + J で結合し、スカルプトモードで R(密度)→ Ctrl + R(リメッシュ)。重要:結合すると、アクティブ以外のオブジェクトのモディファイアは失われます。腕は結合前にモディファイアを適用しておきます。

マスク

腕だけをスカルプトしたいのに、近くの胴体まで影響を受けてしまうことがあります。マスクは、オブジェクト/編集モードの「選択」の逆で、マスクされた頂点はロックされ、変更できません(暗く表示)。

  • Mask ブラシ(M)、投げ縄マスク(Ctrl + Shift + 右クリック)、ツールバーのBox、Line、Polygonなどのジェスチャーツール
  • マスクの反転や消去は、マスクのパイメニュー(A)が便利です。固定したい部分があるときは、マスクを使いましょう。

髪の整形

モディファイアをまとめて適用

Ctrl + A › Visual Geometry to Mesh で、すべてのモディファイアを一度に適用できます。見えているジオメトリが、そのまま編集可能なメッシュになります。この髪のオブジェクトには、ボクセルリメッシュを使わないでください。別々のメッシュのクリーンな四角形トポロジーが、束ごとのスカルプトに役立ちます。

フェイスセットと非表示

スカルプトモードでは、H / Shift H は選択ではなくフェイスセット(色分けされたメッシュのグループ)を隠します。ヘッダーの Face Sets › Initialize Face Sets › By Loose Parts で、つながっていない部分ごとのセットを作れます。

  • フェイスセットにカーソルを合わせて H:非表示。Alt + H:すべて再表示。Shift + H:他のフェイスセットを非表示(すでに非表示があれば全表示に戻る)。
  • フェイスセットはマスクと同様にオーバーレイです。オーバーレイ全体を無効にする(Shift + Alt + Z)か不透明度を下げると、形が見やすくなります。

オートマスキング

毎回隠したりマスクしたりするのは面倒です。ヘッダーの Topology オートマスキングを有効にすると(Alt + A のパイメニューでも切り替え可)、クリックしたジオメトリにつながったものだけをスカルプトします。注意 有効のまま忘れがちです。ブラシの動作がおかしいときは、ヘッダーのオートマスキングのアイコンが白く塗りつぶされていないか確認しましょう。Snake Hook、Inflate、Grab Silhouette などのブラシが仕上げに役立ちます。

手のスカルプト

手は、スカルプトでの形の制御を示す好例です。指が離れなくなるため、ボクセルリメッシュは使いません。Subdivision Surface を適用してから作業します。

Expand(マスクの拡張)と変形

  1. 指先にカーソルを合わせて Shift + A でマスクの拡張を開始し、カーソルを指に沿って動かし、左クリックで確定。
  2. ツールバーの Rotate ツールを選ぶ(スカルプトモードには G/R/S のショートカットがない)。
  3. マスクのパイメニュー(A)で反転し、少しスムーズ。
  4. ギズモで指を回転し、マスクをクリア。他の指も同様に。

ピボットは、拡張したマスクの境界に自動でスナップします。手動で配置するには、表面を指して Shift + 右クリック。Tip マスクを少しスムーズにすると、曲げが鋭くなりません。繰り返しは Shift + R(押しっぱなしも可)。Expand のショートカットは、ステータスバーに表示されます。

フェイスセットの拡張と描画

指ごとにフェイスセットを作ると、個別に隠したりスカルプトしたりできます。つながっているため、ひげのようには自動で分かれません。マスクと同じツール群が、フェイスセットにもあります(W がフェイスセット、A がマスクに対応)。

  • 指先にカーソルを合わせて Shift + W で新しいフェイスセットを拡張。既定は最短距離(Geodesic)で、指が曲がると不正確になることがあります。
  • 数字キー(1〜4)で動作を変更。Diagonals(3)は面全体を埋めながら広がるため、曲がった指でも正確なループに沿って選べます。
  • Draw Face Set ブラシ:ストロークごとに新しいフェイスセットを作り、Ctrl でカーソル下のフェイスセットに追加します。
  • 各指に2つずつフェイスセットを作ります。

フェイスセットでマスク

Expand(Shift + A)の最中に Ctrl を押すと、カーソル下の既存のフェイスセットにスナップして埋められ、複数のフェイスセットを素早くマスクできます(すでに完全に覆われたセットも埋められます)。

ポーズを簡単に:Pose ブラシ

これらの機能の集大成が Pose ブラシで、トランスフォームツールの手間を省けます(精度は少し落ちます)。アセットシェルフで選び、Rotation Origins を Face Sets に設定し、フェイスセットをクリック&ドラッグして回転します。半径(F)で、一度にポーズを付けるフェイスセットの数を変えられます。設定次第で、移動・拡大縮小・伸縮・潰しにも使えます。

解像度はまだ上げず(次のレッスンでディテールを作ります)、Pose ブラシとフェイスセットのマスクで形を整えます。靴にも少し形を付けましょう。

ミニ課題

クローバーのオブジェクトを結合し、スカルプトモードでディテールを整えます。必要に応じてモディファイアを適用してジオメトリを増やし、結合して全体の形と各パーツを自由にスカルプトします。

まとめ

マスクとフェイスセットの作成、オートマスキング、Expand、トランスフォームツールとピボットの移動、Pose ブラシを学びました。
