カーブの利点と注意点

メッシュ以外に、カーブでの作成が向くものがあります。

  • チューブ、ワイヤー、ロープを簡単に作れる
  • 多くの場合、扱いが簡単
  • モディファイアがメッシュを変形するときの元データにも使われる
  • 2D画像エディターの「ペン/ベクター」ツールに近い操作感

注意点(このコースの範囲):表面をメッシュのように編集するには、先にメッシュへ変換が必要です。モードはオブジェクトモードと編集モードの2つだけで、NURBSは扱いません。

ベジェカーブを作る

  1. 全削除して Curve › Bezier を追加(アウトライナーでは緑のカーブアイコン)。
  2. 編集モードでコントロールポイント(中央の点)とその両側のハンドルを G で動かし、形を整えます。拡大縮小や回転でアーチも作れます。
  3. E で押し出して新しいコントロールポイントを作れます。
  4. V(Set Handle Type)でハンドルの種類を変更。Vector にすると直線になり、新しい点にも引き継がれます。種類ごとに色が違います。Automatic は隣の点に追従します。

カーブメニュー(W)

メッシュと同様に Subdivide が使えます。カーブを閉じるには Alt + C(または W › Toggle Cyclic)。

カーブの設定

  • Curve Data の Resolution Preview:コントロールポイント間の点の数を決める。
  • Geometry タブの Extrude を上げると、カーブに厚みが付く。
  • コントロールポイントを選んで Ctrl + T でティルト(ねじり)、Alt + S で半径を調整。サイドバー(N)の Tilt / Radius でも変更可。全選択して90度ティルトすると、押し出しが上向きになる。
  • Extrude を0にして、Bevel タブの Depth を上げると、円断面のチューブになる。Resolution で滑らかさを調整。

2Dカーブ

  1. Curve Circle を追加し、カーブのプロパティで Curve Type を 3D から 2D に変更(Z軸方向の操作ができなくなる)。
  2. Fill Mode を Front にすると、塗りつぶされます。
  3. トップビューで形を編集。別の円を追加(Shift + D で複製も可)すると、最初のカーブから切り抜かれます。
  4. 2Dでも、Extrude や Bevel で厚みを付けられます。

ミニ課題

  • 3Dカーブ:Screwモディファイアを使ってワイングラスを作る(参考資料は自由。ワイングラスには様々な形があります)。
  • 2Dカーブ:Fill Mode を「Both」にしてハート形を作る。グリッドを基準に、左右対称にするため両側のコントロールポイントのハンドル長を揃えます。

まとめ
