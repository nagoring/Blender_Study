インターフェース概要

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Interface Overview

このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

各部の名前を忘れたら、カーソルを重ねるとツールチップで名前と説明が表示されます。

3Dビューポート

  • 最も使うエディターです。グリッドは地面(高さ0)を示し、X=赤、Y=緑、Z=青の軸線で表されます。
  • ギズモ(ウィジェット)はツールを操作するための取っ手で、車のハンドルのようなものです。
  • Blenderはコンテキスト(カーソル位置)に応じて動作するため、操作したいエディターの上にマウスを置く必要があります。

ヘッダー(左から右へ)

  • エディタータイプ:このエリアを別のエディターに切り替える
  • インタラクションモード:オブジェクトモードなど(オブジェクトの種類によって変わる)
  • View / Select / Add / Object メニュー:ショートカットを忘れたときの確認にも使える。モードによって内容が変わる
  • トランスフォームオリエンテーション(既定はGlobal)、ピボットポイント、スナップ、プロポーショナル編集
  • 選択可否・表示の切り替え、ギズモ表示、オーバーレイ(グリッドなどの表示切り替え)、X線表示
  • シェーディング表示:ワイヤーフレームなどに切り替え

その他のエディター

  • アウトライナー(右上):シーンをコレクション(フォルダのようなもの)で整理する
  • プロパティ(右下):シーン・オブジェクト・マテリアル・レンダー・ライト設定やモディファイアの追加など。非常に重要
  • タイムライン(下):キーフレームの確認と、時間のスクラブ

ツールバーとサイドバー

  • T でツールバーを開閉(モードに応じて内容が変わる)。最下部の「Add Cube」ツールで、ドラッグして底面を描き、もう一度クリックで高さを決めて立方体を作れます。
  • N でサイドバーを開閉。Item タブで位置・回転・スケール・寸法を確認/変更、Tool タブでアクティブツールの設定、View タブで焦点距離(例:35)などを変更できます。値はクリックして直接入力、またはドラッグで変更できます。
  • UIは自由に並べ替え可能:Ctrl + MMB ドラッグで拡大縮小、タブは点の列をドラッグで入れ替え、矢印や A で折りたたみ、領域のドラッグで広さを変更。

3Dカーソル

白赤のチェック柄の円が3Dカーソルです。オブジェクトを追加する場所や、一部の操作の基準位置・回転を決めます。隠すことはできても削除はできず、最終レンダリングには映りません。

常に表示される部分

左上のメニュー(保存・開く、Undo/Redo、レンダー、ウィンドウ管理、ヘルプ=マニュアルへのリンク)と、最下部のステータスバー(通常は右下のバージョン番号のみ表示)です。

まとめ

軸の色、ギズモ、コンテキスト依存の動作、ヘッダーの内容、アウトライナー/プロパティ、ツールバー/サイドバー、UIの柔軟性、3Dカーソルを学びました。
