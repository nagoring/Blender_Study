ドライバー

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Drivers

カスタムプロパティとドライバーを使って、服の表示/非表示、IK/FK の切り替え、ビューポートの品質などを、アニメーターが制御できるようにします(練習用:sky_05_ease_of_use.blend、原文ページ参照)。

カスタムプロパティ

スカーフの表示を切り替えられるようにします。まず、クリックできるトグルを作ります。

  1. Root を選びます(Scarf1 でも可)。
  2. Properties › Bone › Custom Properties で New を押し、設定アイコンで編集。
  3. Type を Boolean、Name を「Scarf」、Default Value を True に。説明(Description)は任意で、アニメーターがカーソルを合わせたときに表示されます。
  4. Library Overridable を True に。
警告:ポーズモードで行う カスタムプロパティは編集モードでも作れますが、アニメーターには見えず、編集もできません。
重要:Library Overridable 常に True にします。そうしないと、リグをショットファイルにリンクしたとき、プロパティをアニメーションできません。
ボーンへの追加は、Bone タブで行います。Object や Armature タブと間違えないように。

新しいカスタムプロパティは、サイドバーにもあります。現時点では何も起きません。

スカーフのドライバー

GEO-sky-Scarf のビューポートとレンダーの表示に、ドライバーを作ります。

  1. アウトライナーで GEO-sky-Scarf の Enabled アイコンを右クリック › Add Driver。ポップアップが開き、何も指していない変数「var」が初期設定されます。
  2. 変数の Type を Transform Channel から Single Property に変更。
  3. Object に RIG-sky、Path に pose.bones["Root"]["Scarf"] と入力します。これは「RNAパス」で、そのプロパティの値にアクセスする、Python のコード行です。
  4. 上の Expression には var と入力します(追加の計算なしで、変数の値をそのまま最終値にします)。

Tip Preferences › Interface › Display › Python Tooltips を有効にすると、プロパティにカーソルを合わせて RNA パスを確認できます。

これでプロパティがオブジェクトの表示を制御しますが、動作が逆になっています。

ドライバーの編集

結果を反転するため、Expression を編集します。アウトライナーで GEO-sky-Scarf の Enabled アイコンを右クリック › Edit Driver で、Expression に not var と入力します(これも Python です)。

ドライバーのコピー

レンダーの表示も忘れずに。Enabled アイコンを右クリック › Copy Driver、Render アイコンを右クリック › Paste Driver。

ボーンコレクションの表示

スカーフのボーンは1つのボーンコレクションに入れているため、プロパティがオフのときは、そのボーンも隠せます。今度は速い方法で行います。Root を選び、サイドバーの「Scarf」プロパティを右クリック › Copy as New Driver。「Clothes」ボーンコレクションの Visibility を右クリック › Paste Driver。多くの場合、「Copy as New Driver」がドライバーを素早く初期化する方法です。

注意:ドライブされたプロパティはロックされます アニメーターは、そのボーンコレクションの表示を自分では制御できなくなります。許可したい場合は、階層に「Clothes (Driven)」のようなコレクションを追加します。

FK/IK の切り替え

手足ごとに FK と IK を簡単に切り替えられるようにします。ほぼ自力でできますが、大まかな手順は次のとおりです。

  1. Root に「IK Left Arm」プロパティを作る。Float(0.0〜1.0)か Boolean(True/False)のどちらでも可。既定値は、デフォルトで IK にするかどうかで決めます。
  2. このプロパティで、Forearm.L の IK コンストレイントの Influence と、Hand.L の Copy Rotation の Influence を制御する。
  3. 任意で、「Arms IK」と「Arms FK」のボーンコレクションを左右に分け、それらもドライブする。
  4. 4本の手足すべてで繰り返す。

Tip:既定値へのリセット Blender のどのプロパティも、カーソルを合わせて Backspace で既定値に戻せます。プロパティは Root 以外のどのボーンにも置けます。

品質(Quality)プロパティとドライバー

複雑なキャラクターには、Multires、Bevel、ジオメトリノードなど、重いモディファイアが多くあります。アニメーターは、そうしたモディファイアより、再生の FPS を重視します。ビューポートでの複雑さを、アニメーターが制御できるようにします。

  1. Root に、Quality という Integer のプロパティを追加。Min と Default を 0、Max を 2 に。
  2. 右クリック › Copy as New Driver。
  3. 任意のオブジェクトの Subdivision モディファイアの「Levels Viewport」にペースト。
  4. A ですべてのオブジェクトを選び、ドライバーを貼ったプロパティを右クリック › Copy Driver to Selected。

これで、キャラクター全体のサブディビジョンのレベルを簡単に変更できます。他のモディファイアにも、簡単に応用できます。制作で使えるリグにするために欠かせません。

おわりに

ドライバーの用途は無限で、複雑な式にはまだ触れていません。このコースで、多くのアニメーターが喜ぶレベルの仕上がりにできました。基本を忘れないでください。

  • 高速に:アニメーションに不要なモディファイアは無効にする。
  • 直感的に:探す場所の1〜2番目にあるようにする。
  • きれいに:関係ないものは隠し、ビューポートで見栄えよくする。
