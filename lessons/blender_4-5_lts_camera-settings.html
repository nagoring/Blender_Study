カメラ設定

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Camera Settings

このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

よく使うカメラ設定と、カメラを効率よく扱う方法です。カメラは最終レンダリングに映らないオブジェクトで、シーンを撮影できます。Blender のカメラは一眼レフと完全に同じではありませんが、レンズ、センサー、被写界深度は実際のカメラに近いものです。練習用に watering_can_camera_lighting.blend(原文ページ参照)で、抽象的なシーンを自分で作りましょう。

カメラの基本

カメラは、三角形が付いた四角錐で表されます。三角形が塗りつぶされている(黒)カメラが、アクティブなカメラです。

  • カメラの操作は他のオブジェクトとほぼ同じで、カメラビューの内外で G で移動、R で回転できます。
  • カメラの枠の端をつかむと、焦点距離を調整できます。
  • カメラビューで G を押してから MMB をクリックして離すと、ローカルの Z 軸に沿ってカメラを動かせ、被写体に近づけたり遠ざけたりする速い方法になります。

ウォーク/フライナビゲーション

シーンを調べる楽しい方法です。カメラビューで Shift + `(バッククォート)で有効にします。

  • WASD:前/左/後ろ/右に移動。Q / E:下げる/上げる。
  • Tab:「重力」を有効にして、カメラを平面上の高さ 1.6m に置く。
  • このモードでは、タイムラインを再生していれば、動きを記録できます。V で「ジャンプ」。他の機能はマニュアルを参照。

その他のカメラのヒント

カメラが複数あるとき、Ctrl + テンキー 0 でアクティブカメラに切り替えます。Ctrl + Alt + テンキー 0 で、3Dビューポートの視点にカメラを合わせられます。上記の操作は、View › Cameras にあります。

カメラのレンズ

カメラの Object Data プロパティで設定を確認します。

  • Orthographic(平行投影):3Dビューポートの平行投影と同じ、フラットな投影。Scale で拡大縮小。
  • Panoramic:Fisheye Equisolid などのタイプ。90年代のスケートビデオで見られるような、広角で被写体に近い映像。
  • Equirectangular とミラーボールの種類は、Environment Texture で使うものと同じです。この種類にして、適切なファイル形式(EXR)でレンダリングすれば、3Dシーンを他のファイルのライティングデータとして使えます。
  • Perspective では、Focal Length(焦点距離)の値が低いと「広角」、高いと「フラット」な結果になります。X/Y の Shift でカメラを微調整できますが、値が大きすぎると、面白い反面、望まない結果になる場合もあります。Clipping は、カメラに見える範囲を制限します。最適化やシーンとの交差に便利です。

カメラのセンサー

実際のカメラには特定のセンサーサイズがあり、実写との3D合成のために Blender でも合わせられます。センサーのプリセットを試してみましょう(最終的に焦点距離にも影響します)。

ビューポート表示とガイド

  • Limits を有効にすると、カメラの原点から伸びる線(選択時はオレンジ)が表示され、両端の点とその間の十字が現れます。点と線の内側がレンダリングされるクリッピングの範囲で、十字は被写界深度に使うフォーカス点です。
  • Passepartout は、カメラの周囲を暗くして、最終レンダリングに入る範囲を見やすくします。
  • Composition Guides(構図ガイド)は、カメラとシーンの配置の補助です。このシーンでは「Thirds(三分割)」で配置します。写真家にはおなじみの、バランスの良い画像のための手法です。経験者には平凡に感じても、役立ちます。

Tip トグルの上を左ボタンで押したまま下へドラッグすると、まとめてオン/オフできます(Blender の UI 全体で使えます)。

被写界深度

実際のカメラのように、画像のどこがシャープで、どこがぼけるかを決めます。Depth of Field を有効にして、Focus Distance を調整します。

  • Focus Distance の上で E を押して、オブジェクトをサンプルする。またはオブジェクトを指定すると、その原点がフォーカス点になる。
  • Aperture の F-Stop:値を下げるとぼけが強く、上げると控えめになる。カメラでよく使う値が使える。
  • Blades(絞り羽根の枚数)で、ボケの形が変わる(背景に焦点外のハイライトが多いと分かりやすい)。Ratio を変えると引き伸ばされ、アナモルフィックなボケになる。Rotation でボケや羽根を回転。

レンダーリージョン

画像の特定部分だけをレンダリングします。エリアのプレビューや、処理能力を小さい範囲に集中させるのに役立ちます。

  • Ctrl + B でリージョンを描く(赤い破線の枠)。端を左ドラッグで調整。Ctrl + Alt + B でクリア。
  • Tip カメラビューで、カメラ全体に重なるようリージョンを描くと、カメラの視点だけがレンダリングされます。ただし、最終レンダリングでもレンダーリージョンは有効です。不適切なリージョンは、最終画像を「トリミング」してしまいます。

ミニ課題

ファイル内のモデル(じょうろ、チーズのブロック、ゾウ)で、面白い構図を作ります。前のセクションに触発された、自分の World/環境の色を使います。作りたい構図を考えましょう。例では、各オブジェクトが次のオブジェクトを指して三角形を作り、見る人の視線を枠内で行き来させる「三角形構図」です。構図ガイドと、学んだすべてのツールを使って、自由に作りましょう。

まとめ

ウォーク/フライナビゲーションを含むカメラの操作、カメラ設定がビューやレンダリングにどう影響するか、レンダーリージョンによるレンダリング処理の最適化、自分の構図の作り方を学びました。
