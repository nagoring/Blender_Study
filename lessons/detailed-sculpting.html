ディテールのスカルプト

ノームの小さな形や表面を、ディテールまで作り込みます。大きな形が固まったので、次の内容を学びます。

  • リメッシュで高ディテールにする際の欠点
  • サブディビジョンを使ったスカルプトの理由と方法

リメッシュの限界

胴体をスカルプトモードで、R(密度)→ Ctrl + R(リメッシュ)と、解像度を段階的に上げられます。ただしリメッシュでは滑らかになりません。Smooth ブラシで毎回直すのは大変なので、ツールバーの Mesh Filter(Filter Type を Smooth)で、ビューポートを左から右にドラッグして全体をスムーズにします。ヘッダーの Sculpt › Smooth でも同様にできます。

オーバーレイの Statistics で、アクティブなオブジェクトとシーン全体の頂点数を確認できます。動作が重くなったときの目安になります。

リメッシュでディテールを作る欠点

  • 解像度を上げるたびに手動でスムーズにするのが面倒
  • 手動のスムージングで、スカルプトしたディテールを失うことがある
  • ボクセルリメッシュは、交差する形(指など)をくっつけることがある
  • 数百万頂点では、リメッシュとビューポートの性能が目に見えて落ちる
  • Dyntopo の限界はさらに低く、有効中は50万頂点未満が目安

Multires でのスカルプト

サブディビジョン・スカルプトは最も古い方法で、Multiresolution モディファイアを使います。Subdivision Surface に似ていますが、次の違いと利点があります。

  • 細分化で自動的に滑らかになる
  • 各サブディビジョンのレベルごとにスカルプトでき、大きな変更から細かなディテールまで、レベルを選べる
  • ビューポート、スカルプト、レンダリングで別々のレベルに設定でき、最適化しやすい
  • 低解像度のベースメッシュがあるため、編集モードが速く、UVマップの追加が確実になり、リギングもできる

最大の欠点は、プロポーションの大きな変更が難しい点です。ベースのトポロジーが固定され、変更すると高レベルのディテールが壊れます。全体の形が確定してから Multires に切り替えましょう。

使い方(帽子で試す)

  1. 帽子を選ぶ(Solidify は適用済みに)。
  2. スカルプトモード(Ctrl + Tab)で Ctrl + 2 などで細分化(数字がレベル)。Multires モディファイアが追加されます。
  3. スカルプトモード中は、Alt + 1 でレベルを上げ、Alt + 2 で下げられます。大きな形は低いレベルで、しわなどの細部は高いレベルで。必要なときだけ細分化を進めます。
  4. Ctrl + 数字は、スカルプトモードでは Multires、オブジェクトモードでは Subdivision Surface を追加します。

すでに Dyntopo やリメッシュ済みのオブジェクトの細分化は、うまくいきません(フリーズや長い待ち時間の原因)。三角形や極が多いほど時間がかかり、結果も乱れます。次の「ベースメッシュの生成」を参照してください。すでに Subdivision Surface を適用してしまった場合は、Multires を追加して Rebuild Subdivisions または Unsubdivide ボタンで、低いレベルに戻せます。

ベースメッシュの生成

多くのオブジェクトはリメッシュで作ったため、細分化に向きません。必要なのは、次の条件を満たすクリーンなリトポです。

  • 均等なサイズの四角形(伸びなし)
  • 比較的低い密度(すでに密なメッシュの細分化は遅い)
  • 極(辺が4本でない頂点)が少ない
  • マニフォールドなメッシュ

手作業のリトポは時間がかかるため、内蔵のクアッドリメッシュ(QuadriFlow)を使います。

  1. 安全のため、胴体を Shift + D で複製してキャンセルし、H で非表示にする。
  2. 残った胴体で、プロパティの Object Data(緑のアイコン)› Remesh › Mode を Quad にし、QuadriFlow Remesh ボタンを押して Remesh で確定。
  3. 結果が良くないときは、オペレーターパネル(左下、または F9)の Number of Faces や Seed を変えて、見た目がよく低解像度のものを探す。編集モードでの手動修正も可。

ディテールを取り戻す

Multires で細分化しても、ディテールは失われて滑らかになっています。そこで安全のために残したコピーを使います。

  1. Shrinkwrap モディファイアを追加し、Wrap Mode を Project、Negative を有効にする。
  2. Alt + H で非表示のオブジェクトを再表示し、Target のスポイトで、元のスカルプトした胴体を選ぶ。元の胴体はもう一度 H で隠す。
  3. ディテールが戻るまで十分なサブディビジョンを使う。

手順は多いですが、細かなディテールまで保てます。ギザギザになった面は、スカルプトモードで再度スムーズにします。脚と靴にも同じ方法で、Multires でのディテール作りができます。

ひげのディテール

Multires で Crease Sharp ブラシを使い、毛の溝を彫ります。ブラシ設定の Stroke(Shift + S)の Stabilize Stroke を有効にすると、滑らかな曲線を描けます。

スムーズシェーディングとフラットシェーディング

シェーディングは、オブジェクトを選んで右クリックメニューからいつでも切り替えられます。

  • フラット:作業している形がそのまま見え、ワイヤーフレームなしで解像度が分かります。解像度を上げている途中や Multires のスカルプトでは良い習慣です。3Dプリントでは、実際に出力される形なので、常にフラットにします。
  • スムーズ:のちにレンダリングするなら、実際の見た目に近く、デザインを判断しやすい。テクスチャやシェーディングを付けたモデルでは、ほぼ必須です。

すべてのオブジェクトを、さまざまなブラシでさらに作り込みましょう。手とクローバーはまだディテールが必要で、手には関節やしわも足せます。

まとめ

スムースフィルター、クアッドリメッシュ、Multires による高解像度化、Shrinkwrap でのディテールの再投影、フラットとスムーズのシェーディング、シャープ/クリースブラシを学びました。
