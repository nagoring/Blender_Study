ジオメトリノードの基礎理論

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Geometry Nodes Theory

ジオメトリノードは、ノードベースの操作でオブジェクトを変更する仕組みです。非常に複雑で万能なエディターなので、じっくり取り組みましょう。

ジオメトリノードエディター

作業はジオメトリノードエディターで行い、Geometry Nodes ワークスペースで簡単に開けます。次の要素があります。

  • 最も広い、ジオメトリノードエディター
  • 左のスプレッドシート:アトリビュートや、使用中のドメインなどの情報を表示
  • 結果を見る3Dビューポート

ジオメトリノードの基本

  • アトリビュート:ジオメトリデータブロック内の、要素ごとに保存されるデータ。メッシュの要素(面など)の値を、変更・設定・削除できます。
  • アトリビュートのデータ型:要素に保存されるデータの種類。Float、Integer、Boolean、Vector など。Float は値の間の細かいステップを作れ、Integer のステップは1です(例:Integer なら、チーズのブロックがステップごとに1m動く)。
  • 名前付きアトリビュート:ゾウを頂点ペイントモードで塗ったデータなどから取得でき、あらゆる変形に使えます。UVマップ、頂点カラー、辺のデータなども含まれます。
  • アトリビュートドメイン:メッシュの要素の種類(頂点、辺、面、フェイスコーナーなど)。
  • フィールド:基本的には関数で、ソケットの形で見分けられます。

一般的な作業は左から右へ進みます。ノードの始点と終点の色付きの形がノードソケットで、他のノードにつなげます。例:ゾウの頂点ペイントの赤チャンネルを使い、範囲を絞ってハイライトだけを取り出し、Set Position ノードで位置を変える場所を決めます。別の例では、Switch ノード(Boolean が True/False)で、チーズが回転するかどうかを切り替えます(この例では、Geometry をフィールドとして使用)。

ノードエディターの基本

  • 出力ソケットから左ドラッグして入力ソケットへつなぐ。途中で離すと検索メニューが開き、ノード名を入力して確定すると、自動でつながります。
  • Ctrl + Shift を押しながらノードや出力ソケットをクリックすると、Preview ノードが追加される。結果を見たいノードは、意図してプレビューする必要があります。
  • Ctrl + 右ドラッグで接続を切断(カーソルがナイフに変わり、線を引いて切る)。入力側から接続をドラッグして外すこともできます。

最初のステップ

  1. 新規ファイルで Geometry Nodes ワークスペースを開き、立方体を選んで New を押す(右側に Geometry Nodes モディファイアが追加される)。
  2. Shift + A で追加できるノードのメニューが開く。入力して検索するほうが速い。Mesh › Primitives › Cube を追加。
  3. Cube ノードを右クリックで選び、X で削除。Mesh › Primitives › Cone を追加。
  4. 緑の「Mesh」出力ソケットを、Group Output の「Geometry」入力につなぐ(最後のノード)。

オブジェクトが円錐になりますが、編集モードに入ると、元の立方体は残っています。モディファイアでジオメトリを置き換えているだけです。Group Input は、Geometry 出力ソケットを使った、メッシュの元のジオメトリです。このノードは、3Dビューポートのオペレーターパネルで新しいオブジェクトを調整するのに似て、パラメーターの調整で完全に非破壊の変更ができます。

Ctrl + Shift でプレビューノードが追加され、つないだノードの結果が3Dビューポートに表示されます。出力ソケットが複数あるノードで Ctrl + Shift を押し続けると、出力ソケットを順に切り替えます。Top、Bottom、Side は Boolean のメッシュ選択で、白が選択、黒が非選択です。UVMap は、変更したパラメーターに基づいて生成され、テクスチャを付ける座標に使えます。Tip 切り替えず、見たい出力ソケットを直接選ぶこともできます。

削除と結合

  • Shift + A › Geometry › Operations › Delete Geometry を追加。既存の接続の上にドラッグすると、接続がハイライトされ、左クリックで確定するとそこに挿入されます。
  • Ctrl + Shift + 左クリックで Delete Geometry をプレビューし、Side 出力を Selection 入力につなぐと、側面が削除されます。選択以上に削除されたように見えるのは、ノードが Point(頂点)に設定されているためです。Face にすると、編集モードのように面だけが削除されます。
  • Mesh › Primitives › Ico Sphere を追加し、Join Geometry ノードに両方をつなぎます。Join Geometry のソケットが大きいのは、複数のジオメトリをつなげるためです。

スプレッドシート

新規ファイルの Geometry Nodes ワークスペースで、スプレッドシートを見てみましょう。Mesh の下には、立方体から読み取った、8頂点、辺、面、フェイスコーナーのドメインが表示されます。

  • Spiral(Shift + A › Primitives › Spiral)は、じょうろの注ぎ口や持ち手で使ったカーブに似たカーブです。Ctrl + Shift でプレビューすると、コントロールポイントが 65(既定)、スプラインが 1 と表示されます。
  • Curve 出力をドラッグして離すと検索メニューが開く。「To point」で Curve to Points を追加すると、各コントロールポイントに点が作られる。既定は Count(Integer で 10)で、実際のコントロールポイントを見るには Evaluated にする(点の数が 65 に戻る)。
  • Volume Cube:テクスチャで操作できる、ボリュームを持つ立方体。Checker Texture を追加し、Fac 出力を Density 入力へつなぎ、Scale を下げると、テクスチャでボリュームの密度が変わる。
  • Volume Cube の後に Distribute Points in Volume を追加し、Grid に設定すると、ボリュームに基づいた格子状に点が追加される。Spacing を 0.1 にすると、密度が上がる。
  • 複数の入力やパラメーターを選ぶには、最初のパラメーターから下へ左ドラッグする。
  • Group Input の Geometry 出力の後に Mesh to Points を追加すると、ドメイン(既定は頂点)に基づいて点が作られる。ドメインを変えて結果を確認しましょう。
  • Instance on Points:点の位置にインスタンス(メッシュ、カーブなど)を配置する。両方の Points ソケットがつながっていることを確認する。Group Input の Geometry 出力を Instance 入力につなぐと、立方体のジオメトリがインスタンスとして使われる。Scale を下げ、スプレッドシートで、6個のインスタンスになったことを確認する。スプレッドシートには、プレビューノードで選んだものが表示される。

まとめ

アトリビュートが要素ごとに保存されること、データ型(Float、Integer、Boolean、Vector)、名前付きアトリビュート、アトリビュートドメイン、フィールドとソケットの形の意味、スプレッドシートの読み方、各ノードの使い方、左ドラッグで複数入力を一括変更する方法を学びました。
