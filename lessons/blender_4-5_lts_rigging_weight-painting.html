ウェイトペイント

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Weight Painting

ウェイトペイント(「スキニング」とも呼ぶ)は、頂点グループを作る便利な方法です。まず頂点グループとは何かを理解します(練習用ファイル:sky_02_armature.blend、原文ページ参照)。

頂点グループ

頂点をグループに整理できます。さらに、各頂点は、各グループに対するウェイト(0.0〜1.0の値)を持ちます。

頂点グループを作る(左上腕で試す)

  1. 左上腕のボーン名「Upperarm.L」を確認する。
  2. 左上腕のオブジェクト「GEO-sky-Upperarms.L」を選び、Tab で編集モードに入り、全頂点を選択。
  3. Properties › Mesh › Vertex Groups で + を押し、グループ名をボーンとまったく同じ名前(Upperarm.L)にして Assign。

正しくても間違っていても、この時点では何も起きません。確認は次の手順で行います。

アーマチュアモディファイア

キャラクターを変形する主な手段はArmature モディファイアです。上腕のオブジェクトに追加すると、頂点グループがあれば、上腕が動くようになります。

重要 再生のパフォーマンスは自分で守る必要があります。Armature モディファイアは Subdivision モディファイアより上に置きます。モディファイアスタックは毎フレーム上から順に実行され、頂点の変形には計算が必要です。CPUが変形する頂点を、できるだけ少なくしましょう。
Tip Profiling Buddy アドオンで、モディファイアの評価時間を確認できます。

オートマチックウェイト

面倒な方法を体験したので、プロの方法に移ります。

  1. すべて選択し、リグを Shift で追加選択する。
  2. Ctrl + P › With Automatic Weights。
  3. メッシュオブジェクトを Shift で選び、Armature モディファイアを Alt + ドラッグでスタックの一番上へ(全オブジェクトに適用)。

これで、ここまでの手順をすべて、ずっと速く行えます。このオペレーターはオブジェクトをリグにペアレントもするので、前の手順で別に行う必要はありません。各オブジェクトに近くのボーンに対応する頂点グループができ、Armature モディファイアがスタックの一番上に置かれます。Sky をポーズさせられます。

ウェイトペイント

自動の結果は完璧ではありません。首を回すと、スカーフの動きがおかしくなります。スカーフの上端を、胸に完全に割り当て、首と頭には割り当てない必要があります。自分でウェイトを塗りましょう。

  1. リグを選び、調整したいメッシュ(GEO-sky-Scarf)を Shift で追加選択して、アクティブにする。
  2. ウェイトペイントモードに切り替える。
  3. 首のボーンを選ぶ(左クリック選択では、左クリックがペイントになるので Alt が必要)。首のウェイトが、値に応じた色で表示される。

ショートカット

  • 左クリック:ペイント。Ctrl + 左クリック:逆のブラシでペイント。Shift + 左クリック:ウェイトをぼかす。
  • F:ブラシのサイズ。Shift + F:強さ。Ctrl + F:ブラシのウェイト値。
  • 1:面選択のマスクを切り替え(選択は編集モードで行うのがおすすめ)。2:頂点選択のマスクを切り替え(ほぼ同じ)。

ブラシ設定

よくある問題:背中の頂点を塗るために何度もキャラクターを回す必要がある、スカーフの内側の頂点を塗れているか分からない、首に最大の影響を塗っても他のボーンが同じ領域に影響する、ブラシのウェイトを1.0未満にすると Ctrl + 左クリックでウェイトを完全に消せない、などです。慣れるために、よく切り替える設定を知っておきましょう。

  • Accumulate:オンだと、クリックし続けなくても塗り重ねられる。低い強さと併用すると精密に塗れる。広い範囲に一定量のウェイトを足したいときはオフに。
  • Front Faces Only:オンだと、見える部分だけを塗れる。ここではオフのままで。
  • Falloff Shape:カーソル中心の球状か、ブラシカーソルから投影される円柱状か。メッシュを貫通して塗りたいときは後者がほぼ必須ですが、注意が必要。

恒久的に変更しておくとよい設定:

  • Mix Mode:「Add」にすると、Ctrl + 左クリックで一貫してウェイトを引ける。
  • Auto-Normalize:1頂点の、変形するすべてのグループのウェイトの合計を、常にちょうど1.0にする。赤は、そのボーンが完全にその領域を担当し、他の影響がない、という意味になる。
  • Multi-Paint:複数のボーンを選び、影響をまとめて塗れる。ストロークをグループに賢く分配するため、直感的に使える。
重要 Blur ブラシの設定は別です。T でツールバーを開き、Blur ツールを選んでカスタマイズします。ブラシの設定は、各ブラシのローカルコピーを作るまで保存されません。サイドバーの Brush Asset パネルで作れます。

変形テストアニメーション

各ボーンを可動域いっぱいに回してキーフレームを打った、テストアニメーションを作ります。

  • アニメーションを再生しながら、キャラクターの周りを回って、あらゆる角度から変形を確認できる。
  • 実際のリグでは、コンストレイントのためにデフォームボーンを動かせないことがあるが、タイムラインでキャラクターを動かして、ウェイトペイントへの反応を確認できる。

重要 リグからアクションの割り当てを外してファイルを再読み込みすると、アクションは永久に失われます。Fake User を設定しておきましょう。また、X-Axis Mirror はポーズをミラーしますが、選択していないボーンにはキーを打ちません。

最終的なウェイト

これまでの内容を使って、Sky のウェイトペイントを仕上げます。まず、前の章の知識の復習として、スカーフ用のボーンを追加します。そして、テストアニメーションで変形の改善できる箇所を見つけ、ウェイトを改善します。完成ファイル:sky_03_weights.blend(原文ページ参照)。

まとめ

頂点グループとボーンの変形の関係、Armature モディファイアとスタック内の位置、オートマチックウェイト、ウェイトペイントモードのブラシと設定、テストアニメーションによる変形の確認を学びました。
