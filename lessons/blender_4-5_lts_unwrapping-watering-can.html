じょうろをUV展開する

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Unwrapping Watering Can

UVグリッドを使って、じょうろを展開します。ここで作るUVレイアウトは、のちのジオメトリノードの「構築」エフェクトにも影響しますが、あとから変更もできます。

展開を始める

  1. watering_can.blend を開き、UV Editing ワークスペースへ。作業を速くするため、Mirror モディファイアは有効のままです。
  2. Material タブで New を押し(4.5.3 では少しフリーズすることがあります)、名前を「watering_can」に。
  3. Base Color の黄色い入力 › Image Texture › New。名前を「grid」、Generated Type を UV Grid にして New Image。ビューポートシェーディングで Texture を有効にして、モデル上でグリッドを確認します。
  4. 注ぎ口と持ち手の周囲にシームのループを入れる。オブジェクトの「自然な」切れ目にシームを入れ、片側の中央にもシームを入れる。注ぎ口の先(ローズ)の周りにも入れて展開する。
  5. Mirror モディファイアを適用して、もう一度展開する。

ライブアンラップ

本体中央の大きな部分のUVが「曲がって」います。Live Unwrap と頂点のピン留めで解決します。

  1. UV › Live Unwrap をオンにする。
  2. UVの「上」と「下」(実際は側面)を UV › Pin(P) でピン留め。ピン留めした頂点を回転し、垂直方向に動かして、側面をまっすぐにする。
  3. さらに、上端か下端のピン留めした頂点を選び(持ち手や注ぎ口の頂点は含めない。これらもまっすぐになってしまうため)、W のコンテキストメニューから Align Auto を選んで整列する。
  4. 動画のように、上下にシームを追加する。
  5. UV › Pack でUVアイランドを近くに詰めて、整理する。
  6. L(Select Linked)で、メッシュのアイランドを選択できます。UVエディターでも3Dビューポートでも、カーソルを合わせて L を押すだけです。本体の上下の部分を L で選び、U › Unwrap Minimum Stretch で展開し、再度パッキングする。

Average Island Scale

UVアイランドのスケールがバラバラな場合は、すべてのUVを選び、UV › Average Island Scale で揃え、再度パッキングします。

サブディビジョンサーフェスのクリース

モデリングの章で扱わなかったのは、Subdivision Surface モディファイアを追加するとUVに影響することを示すためと、ジオメトリノードの章への準備のためです。

  1. Layout ワークスペースで、Texture シェーディングを有効にし、W › Shade Smooth で全体をスムーズシェーディングに。
  2. Ctrl + 2 でレベル2の Subdivision Surface を追加。モディファイアのオン/オフ(または Ctrl + 0 と Ctrl + 2)で、UVが変わることを確認できます。
  3. 解決策はクリースです。編集モードで、クリースを付ける辺ループを選び、Shift + E でドラッグして、0〜1の値を設定します。シームのように辺の色が変わる辺データで、元のトポロジーの近くに、より鋭い角が作られます。
  4. 動画のようなループと、じょうろの底にクリースを付ける。UVがおかしな動きをする箇所には、「サポートループ」を足す。モデル全体を見て、クリースを付けられる箇所を探しましょう。

この章は以上です。次の章では、じょうろから離れて、キャラクターのリギングを扱います。

まとめ

ライブアンラップとピン留め、コンテキストメニューから Align などの操作を使うこと、L による選択、Unwrap Minimum Stretch、Average Island Scale、Subdivision Surface でのクリースを学びました。
