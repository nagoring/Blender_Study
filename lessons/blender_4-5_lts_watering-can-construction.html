じょうろの構築

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Watering Can Construction

ジオメトリノードで、じょうろが組み上がる「構築」アニメーションのエフェクトを作ります。

パート1:構築エフェクト

  1. watering_can.blend を開き、新しいジオメトリノードの設定を追加。Shift + Tab でスナップを有効にすると、ノードを揃えやすく、見通しが良くなります。
  2. Shift + A › Named Attribute を追加し、空欄を左クリックして、メッシュにあるアトリビュート一覧から「UVMap」を選ぶ(Data タブでも確認可)。
  3. Group Input と Named Attribute を Ctrl + Shift でプレビューすると、3Dビューポートに UV の色が表示されます。UVMap は Vector 型で、軸ごとに分けられます(UV は水平と垂直、つまり X と Y だけ)。
  4. Separate XYZ を Named Attribute の出力につなぐ。Vector 入力と、軸に対応する3つの Float 出力があります。X と Y をプレビュー。
  5. Delete Geometry をつないでプレビュー(オブジェクトが全部消える)。
  6. Greater Than(Compare ノード)を追加し、B の値を変えると、値が他方より大きいかを比較して出力します。これを Delete Geometry の Selection につなぎます。
  7. 1つの軸ではなく、Add の Math ノードを Separate XYZ と Greater Than の間に置いて、両軸を足し合わせると、別の構築エフェクトになります。

パート2:構築エフェクトの調整

ノードの設定とUVアイランドを変えて、どの部分が先に作られるかを決めます。

  1. まず Subdivision Surface モディファイアを削除し、代わりに Delete Geometry の後ろに Subdivision Surface ノード(Level 2)を追加すると、辺が丸くなります。
  2. ジオメトリノードエディターを分割して UV エディターを追加すると、UVアイランドの位置や回転を変えやすくなります。エディターの右上の角にカーソルを置くと「+」になり、左へドラッグすると縦に分割できます(別の分割方法)。
  3. Compare ノードの B の値を変えると、B を上げたときにどのUVアイランドが消えるか分かります。下の部分が最初に作られ、その後に残りが見えるように、UVアイランドを並べ替えます。注ぎ口や持ち手などが「浮いて」見えないように注意します。アイランドを回転すると、効果の向きが反転します。UVアイランドの移動と B の値を試しましょう。

パート3:クリースを戻す

Subdivision Surface モディファイアを削除したため、クリースもなくなりました。ジオメトリノードで戻します。Named Attribute を複製して「crease_edge」を選びます(出力ソケットがグレーになり、Float 値だと分かります)。この Attribute 出力を Edge Creases 入力につなぎます。ノードを選んで M を押すとミュートでき、そのノードが結果にどう影響するかを確認できます。

パラメーターを作る

ほかのモディファイアのように、ジオメトリノードでも独自のパラメーターを作れます。B の値を 0 にしても、底が見えたままです。すべてのUVアイランドを上に動かして、何も見えない状態にしましょう。B 値のソケットを左へドラッグして「Group Input」を検索して追加すると、モディファイアタブに B のパラメーターが追加されます。サイドバー(N)の Group Sockets で名前を「Evolution」に変更します(機能や結果を表す名前にします)。Default、Min、Max も設定できます(Default が 0 なのは、Group Input をつなぐ前に設定した値だからです)。Min を 0、Max を 3 程度(じょうろが完全に見える値)にします。モディファイア名は「GN-construction_fx」にします(GN は Geometry Nodes)。サルに追加して、値を変えてみましょう。

完成ファイル:watering_can_gn.blend(原文ページ参照)。シェーディングの章で、ジオメトリノードエディターに戻ります。

まとめ

構築エフェクトの作り方、エディターの隅にカーソルを置いて横や縦にドラッグして分割する方法、M でノードをミュートして違いを確認する方法を学びました。
