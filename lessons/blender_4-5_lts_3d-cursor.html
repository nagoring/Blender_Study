3Dカーソル

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: 3D Cursor

このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

3Dカーソルをスナップする

  1. 立方体を追加します。オレンジの点がピボットポイント(変形の基準点)です。
  2. 編集モードで頂点を1つ選び、Shift + S(スナップのパイメニュー)から Cursor to Selected を選ぶと、3Dカーソルが選択位置に移動します。辺を選べばその中点になります。

原点(ピボット)を3Dカーソルに移す

カーソルを合わせたあとオブジェクトモードに戻り、Object › Set Origin › Origin to 3D Cursor。回転やスケールで効果を確認できます。

オブジェクトをカーソル位置へ移す

別のオブジェクト(立方体やUV球)を選び、Object › Snap › Selection to Cursor でカーソル位置へ移動します。他のスナップ項目も試してみましょう。

ミニ課題

下が大きく上が小さいスザンヌ(モンキー)の塔を作ります。G・R・S で調整し、倒れずに立ちそうか周囲から確認します。まず Shift + C(または Shift + S › Cursor to World Origin)で3Dカーソルを世界の原点(0,0,0)に戻し、平面を追加してから積み上げます。

まとめ

3Dカーソルの移動、カーソルを使った原点の設定、スナップメニューでオブジェクトをカーソル位置へ移す方法を学びました。
