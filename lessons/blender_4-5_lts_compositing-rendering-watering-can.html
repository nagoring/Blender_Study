じょうろのコンポジットとレンダリング

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Compositing & Rendering Watering Can

じょうろのレンダリングを調整して、最終的に書き出します。書き出す前に、独自のコンポジットのノード構成で、画像を芸術的に仕上げても構いません。

レンダーパスを有効にする

コンポジットの前に、使うレンダーパスを有効にします。View Layer プロパティタブで、使いたいパスを有効にします(ここでは、構築/溶接エフェクト用に Emission だけ)。パスを設定した後、F12 で1回レンダリングします(有効にしたレンダーパスが保存され、コンポジターで使えるようにするため、再度のレンダリングが必要)。1フレームをレンダリングした後、Compositing ワークスペースで「Use Nodes」を有効にすると、Render Layer、Composite、Viewer ノードが追加されます。

コンポジターのワークフローのヒント:V でバックドロップを縮小、Alt + V で拡大、Alt + MMB でバックドロップを移動。

グレアを追加する

Emission ソケットから、Streaks(Streak)に設定した Glare ノードを追加します。Glare ノードには3つの出力があります。

  • Image:画像にグレアを重ねたもの。
  • Glare:グレアの効果のみ。
  • Highlights:画像のどれだけがグレアに影響しているかを表示(しきい値を下げると、グレアに使われる量が増える)。

Streaks を 2 にして、暖色のティントを加えます。Add の Mix Color ノードを追加し、Glare 出力を B に、Render Layer の Image を A につなぎます。Mix Color の Factor でグレアの強さを調整できますが、Glare ノードの Strength を使う場合とは結果が違います。さらに Bloom の Glare ノードも、動画のように追加します。

カラーグラデーションを追加する

わずかなレンズのグラデーションを作ります。

  1. Box Mask を追加。ウィジェットで、移動・回転・スケールするか、パラメーターを使う。ブラーをレンダリング範囲の外まで正しく適用するため、X のサイズを 1.1 に。
  2. Blur ノードを追加し、256〜400 に。
  3. Color Ramp を、新しい Mix Color(Multiply、または望む効果に応じた別のブレンドモード)につなぐ。左が白、右がわずかな色になるようにストップを変更し、好みの色に調整。

ビネットを追加する

Ellipse Mask を追加し、ウィジェットやパラメーターで楕円を画像の境界に合わせます。Blur と Mix Color ノードを複製し、Blur のサイズと、Color Mix の Factor を調整します。

簡単なフィルムグレインを追加する

  1. White Noise ノードを追加し、4D に設定する(ノイズを変化させる「シード」パラメーターが現れる)。
  2. Value ノードを追加し、「W」入力につなぐ。#frame と入力すると、このノードの値が現在のフレームになる(ドライバー、常に紫色で表示、による簡単な自動アニメーション)。
  3. Mix Color ノードを複製して Overlay にし、Factor を調整。

フレームの追加

「glare」「color gradient」「vignette」「film grain」などの名前でフレームを追加します。

最後の調整

Gamma、Exposure、RGB Curves、Color Balance のノードで、色を調整します。この例では Gamma と Exposure のノードだけを追加しましたが、色調整のノードはどれでも試してみましょう。

Tip コンポジットでは、エフェクトを意味のある順序で適用しましょう。例えば、グレアのエフェクトが、ビネットの手前に来るべきではありません。

アニメーションの書き出し

  1. Output プロパティタブで、File Format を PNG に。
  2. Blender が連番画像を書き出す新しいフォルダを作り、選択する。
  3. 出力名を「watering_can_weld_####.png」などにする(# の部分がフレーム番号になる)。
  4. 確定して保存し、Ctrl + F12 でレンダリングを開始。

ほかの画像形式と、その扱い方も見てみましょう。

まとめ

画像に影響するコンポジットのノードツリーの作り方と、# をフレーム番号として使った連番画像の書き出し方を学びました。
