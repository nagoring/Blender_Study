便利なアドオン

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Useful Addons

作業を速くするために有効にできる、便利なアドオンの紹介です。Extensions Platform で探せ、Preferences の Get Extensions タブから、すべて利用できます。

使いやすさ

全般的なワークフローを速くするアドオンです。

  • Copy Attributes Menu:さまざまなデータを、Ctrl + C でコピー、Ctrl + V でペーストして、簡単にコピーできる。
  • Node Wrangler:シェーダーエディター、ジオメトリノードエディター、コンポジターで、ショートカットなどによりノード編集のワークフローを速くする。

モデリング

モデリングの速度と柔軟性を高めます。

  • LoopTools:トポロジーを操作しやすくする、複数のメッシュモデリングツールを追加。
  • Bool Tool:ショートカット Ctrl + Shift + B で、ブーリアンを素早く追加。
  • F2:編集モードで簡単に面を作れる(モデリングの章で紹介済み)。
  • Cell Fracture:選択したオブジェクトに基づいて、破片を作る。岩のベース作りや、リジッドボディのシミュレーションに便利。

テクスチャリングとUV展開

テクスチャリングとUV展開のワークフローを改善します。

  • Texel Density Checker:UVのマッピングが、使うテクスチャの解像度(密度)と一貫しているかを確認する。使い方はUV展開の章を参照。
  • Mio3 UV:UVデータを操作・整理する、多くの便利なツールを提供。
