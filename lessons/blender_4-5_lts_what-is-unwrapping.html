メッシュのUV展開とは何かと、UVエディターを紹介します。次のレッスンでじょうろを展開します。

UV展開とは

3Dモデルを平らな2Dレイアウトに展開(開く)することです。箱を折り畳んで立体にしたものを、逆に開くイメージです。U は水平軸、V は垂直軸を指します。原文ページから立方体の展開の例(.blend、CC-BY)をダウンロードでき、Space でアニメーションを再生・停止できます。UVエディターでは「選択の同期」が有効なので、編集モードと同じ要素が選択されます。

注意 画像エディターとUVエディターは似た機能を持ちますが、用途が違います。混同しないようにしましょう。

UVエディターの紹介

  • 新規ファイルで UV Editing ワークスペースを開きます(既定で編集モード)。Layout に似ていますが、タイムラインがUVエディターに置き換わっています。
  • UVエディター右上に、アクティブな「UVMap」の名前が表示されます(新しい展開の既定名)。
  • 左側に、編集モードと同様の選択モード。サイドバー(N)に Image、Tool、View のオプションがあります。
  • オーバーレイで、グリッドの調整、UV Stretch(歪みの表示)などを設定できます。青は歪みがほぼない、赤は大きく伸びている状態を示します。

展開とシーム

  1. 立方体を追加し、UV Editing ワークスペースへ。既定の立方体は展開済みですが、シームが見えていません。UV › Seams from Islands でシームを作れます。アイランドは、展開内でグループ化された、独立した面の領域のことです。3Dビューポートでは、一部の辺が赤くなり、これがシームです。
  2. Tip 辺のデータ(シーム、クリース、Freestyle、シャープ、ベベル)は、色で区別して表示されます。
  3. 編集モードですべての要素を解除(Alt + A)すると、UVエディターは空になります。
  4. 面の4辺すべてがシームになるように辺を選び、Ctrl + E › Mark Seam(辺が赤くなる)。
  5. 全選択して U でUnwrapメニューを開き、Unwrap Angle Based(最も一般的な方法)。1つの面が、残りの立方体から分離されます。
  6. UVエディターでも G、R、S が使えます。左上の UV Sync Selection を有効にすると、UVエディターと3Dビューポートの選択が同期されます(UVレイアウトは消えません)。
  7. シームを数本消すには Ctrl + E › Clear Seam。再度全選択して U で展開します(UVエディター内で U も可)。

テクスチャを追加する

UVレイアウトの歪みを確認するには、グリッドテクスチャがよく使われます。UV Stretch が数学的なのに対し、こちらは見た目で確認できます。

  1. Material タブの Base Color の黄色い入力ソケットを選び、ノードの一覧から Image Texture を選ぶ(ノードは後で扱います)。
  2. UVエディターで New を選び、名前を「Grid」、Generated Type を UV Grid にして New Image。
  3. Material タブに戻って、グリッドテクスチャを選択。
  4. 3Dビューポートでは、ビューポートシェーディングを Material から Texture に変更しないと見えません(メニューが見切れたら、MMB で左にドラッグ)。

これで、UVレイアウトを動かして、3Dビューポートでの変化を確認できます。

UV編集のヒント

  • 編集モードでスライド(G + G)すると、既定で「Correct UVs」が有効で、UVレイアウトを保ったまま頂点や辺をスライドできます。
  • シームがないまま展開すると、画面下に警告が出ます。シームを加えると警告は消えますが、展開が十分な状態という意味ではありません。UV Stretch かグリッドテクスチャで確認しましょう。
  • 複数のオブジェクトを選んで編集モードで展開すると、UVが1つのレイアウトにまとめられます。オブジェクトが増えるほど、解像度が下がります。

アイランドのパッキング

原文ページの「Cubetube」(CC-BY)で試せます。UVエディターで UV › Pack Islands を開くと、設定のポップオーバーが出ます。

  • Shape Method:アイランドの形の計算方法。Boundary Shape の「Hull」は形の簡略化。Exact Shape は正確な形を計算するため、より効率的に詰められます。
  • Rotation Method:Any(任意の向き)、Axis-aligned(水平/垂直)など。
  • Margin Method:アイランド間の余白。ベイクで役立ちます。

UVとテクスチャのヒント

(任意)2のべき乗

画像ベースのテクスチャは、解像度を2のべき乗にすると、CGで最も効率的です。1024×1024(1k)、2048×2048(2k)などで、ほかに 128、256、512、4096(4k)があります。処理が効率的になり、レンダリングも速くなります。

テクセル密度

実世界の画像テクスチャを使うときは、テクスチャとUVのスケールを考える必要があります。方法は次の2つです。

  • アーティスティックに決める:制作によっては、最も詳細なショットやアセットを基準に、残りを決める。スタイルやサイズの関係で変わります。じょうろは、外部の画像データがなくプロシージャルなテクスチャなので、この方法で作りました。
  • テクセル密度で計算する:UVのサイズを計算で決めます。

例:Poly Haven などの、無料でタイル可能なテクスチャ(1K)をダウンロードし、プロジェクトの「textures」フォルダに置きます。Base Color に Image Texture を追加し、Diffuse(diff)の画像を選び、UV Editing ワークスペースで Texture 表示にします。Preferences(Ctrl + ,)› Get Extensions で、「Allow Online Access」を有効にし、「Texel」で検索して Texel Density Checker をインストールします(拡張機能とアドオンは、ほぼ同じものです)。UVエディターのサイドバー(N)に、新しい Texel Density タブが現れます。

手計算では、テクスチャ解像度を、オブジェクトの実寸で割ります。1024px ÷ 200cm(2m の立方体)= 5.12 px/cm。Texture Size を 1024px、px/cm を 5.12 にして Set TD を押すと、UVがその密度になります。立方体を複製して半分に拡大縮小(S + .5)し、もう一度 Set TD を押すと、UVが縮小され、同じテクセル密度になります。
