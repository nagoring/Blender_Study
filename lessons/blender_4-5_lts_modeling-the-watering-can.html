じょうろをモデリングする

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Modeling the Watering Can

🎬 このレッスンの動画は原文ページで視聴できます。 原文ページを開く(動画付き)
このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

ここまでの知識を使って、スタイライズされたじょうろをモデリングします。流れは、(1)円から本体の土台を作る、(2)持ち手と注ぎ口用に2本のカーブを追加する、(3)カーブをメッシュに変換して本体につなぐ、(4)仕上げ、です。不明な点は原文の動画を確認してください。

設計図のポイント

  • 持ち手と注ぎ口の下端は同じ高さ(見た目と、カーブをつなぎやすくする技術的な理由の両方)。
  • 持ち手はほぼ正円で、持ち手と注ぎ口は本体の中心に配置する。
  • 本体上部の開口部は、側面(Right ビュー)でわずかに傾いている。
  • 素材は金属で、モデリングにも影響する。

1. 本体の土台

  1. 全削除し、32頂点の円(半径 0.2)を追加。必要ならリファレンス画像を設定。Right ビューで作業します(設計図に合わせるため)。
  2. 円を上へ押し出して(例:0.4)、先細りの形にする。
  3. 下と中央にループカットを入れ、中央のループを拡大してベベル(C で交差を防ぐ)。重なった頂点は M › By Distance で統合。
  4. 下側の辺ループを F で塞ぎ、インセットでわずかなへこみを作る。最後のインセットを確定したあと M › At Center で三角形ファンにする。
  5. 上側も辺ループを F で塞いでインセットし、中央にループカット。Ctrl + B で5セグメントのベベル。上面(N-gon)を Right ビューで回転させ、必要なら Ctrl + V › Smooth Vertices で滑らかに。インセットしてN-gon面を削除し、開口部を作る。
  6. 上部に小さなディテールを追加:下端用と上端用のループを作り、片方をスライド、拡大、ベベル。

2. カーブ(持ち手と注ぎ口)

  • ビューポートオーバーレイの Geometry › Wireframe で、オブジェクトモードでもトポロジーを確認できます。
  • メッシュの円を基準として追加します(芸術性と幾何学的な比率のバランスを取るのに便利)。持ち手の上下が本体と接する位置に置きます。
  • Shift + S でカーソルを基準円にスナップし、Curve › Circle を追加して位置・回転・スケールを合わせる。
  • 編集モードで V › Free にして W › Subdivide。Free にするのは、Automatic と違って他のポイントを動かさず、正円を保てるため。
  • 本体と重なる3つのコントロールポイントを選び、Y で分離して削除。残りを E で本体の内側へ押し出し、基準円に沿わせる。
  • Curve Data で Depth を 0.1 以上に。
  • 持ち手が本体の中央付近で、4つの面の範囲に収まるようにしておくと、後でつなぎやすくなります。
  • 注ぎ口:カーブを Shift + D で複製し、右上のポイント以外を削除。本体と交差するポイントを持ち手の下端と揃える。
  • 本体に、カーブの交差位置の上下へ2本のループを追加。必要なら両カーブをまとめて編集モードに入れ、ポイントを少し上へ移動。2本のループの間に Ctrl + R › 5 でさらに5本追加。

3. カーブをメッシュへ変換

  • カーブを選び、Object › Convert › Mesh。本体の内部に入っている部分は削除します。
  • オーバーレイの Statistics で、選択数と合計の頂点・辺・面数を確認できます(Preferencesでシーン統計をステータスバーに表示する方法もあり)。

4. カーブを本体にスナップ

  • 本体の編集モードで8つの面を選び、インセット(カーブと交差しない範囲)。ループをカーブに近づけます。
  • ヘッダーのスナップで Face Nearest を有効にし、辺ループを選んで G + Y で動かしながら Ctrl を押して吸着。動かしすぎると持ち手の形が歪むので、ゆっくりと。
  • Face Nearest は、スナップ中に見つけた全ジオメトリを対象にします。Face Project は見えない(隠れた)頂点を考慮せず、誤ってスナップします。
  • 持ち手の上側も同様に。動画では Knife(K、Cut Through)を使い、G + Z で動かしています。本体上面を変更した場合は、持ち手のループを再度スナップします。
  • インセットしたループをスライド(C でクランプ)して、持ち手に近づけます。

5. カーブをつなぐ

  1. 頂点を円形に整え、8つの面を削除して穴を開ける。
  2. オブジェクトモードで持ち手、続けて本体を選び(Shift)、Ctrl + J で結合。
  3. 編集モードで、穴の辺ループと持ち手の辺ループを選び、Ctrl + E › Bridge Edge Loops。
  4. 三角形やねじれがないか確認します。ある場合は、本体のループ数が合っているか確認するか、オペレーターパネルでブリッジを「ツイスト」させます。
  5. 持ち手の上側、注ぎ口も同様に。

6. 仕上げ

  • 注ぎ口の先(ローズ)を Shear(Shift + Ctrl + Alt + S、または Mesh › Transform › Shear)で少し傾け、辺ループを F で塞ぎ、複数回のインセットで内側の筒を作る。本体まで筒全体を作り込むのは非効率です。
  • Tip 見えない場所にジオメトリのディテールを足さない。メモリと処理を消費します。例外は、3Dプリントや製品の説明図などです。
  • 半分を削除して Mirror モディファイアを追加。X線で誤った選択を確認(Shift で解除)し、Clipping を有効にして、つながりを保つ。
  • 法線の確認:X線にしたとき、本体と注ぎ口/持ち手でコントラストが違う場合は、法線が不揃いの可能性があります。全選択して Mesh › Normals › Recalculate Outside。メッシュ編集モードのオーバーレイで Display Normals や Face Orientation を有効にすると、確認できます(裏側は赤で表示)。法線は、シェーディングやライティング、モディファイアの挙動、オペレーターの結果に影響します。
  • つないだカーブ部分(注ぎ口/持ち手)の3本の辺ループにベベルを数セグメントかけて、より有機的な移行にする。
  • 名前を GEO-watering_can に(GEO- はジオメトリオブジェクトの接頭辞)。基準の円を削除し、コレクションを「watering_can」に改名。
  • 保存:「Projects」フォルダの下に「watering_can」フォルダを作って保存するなど、探しやすい場所に。

まとめ

単純な形を基準にしたモデリング、追加ループでメッシュ同士をつなぐ考え方、スナップの利用、見えないディテールを避けること、法線の検出・表示・再計算を学びました。
