基本のスカルプト

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Basic Sculpting

基本を学ぶため、ここでは目的を決めずに自由にスカルプトします。ブラシの使い方に慣れ、最も重要なブラシを扱います。また、メッシュの解像度を上げ下げする2つの機能(ボクセルリメッシュとダイナミックトポロジー)と、対称を保つミラーも学びます。

スカルプトワークスペース

スプラッシュ画面のテンプレートで Sculpting を選ぶと、十分に分割された立方体と、「Sculpting」「Shading」の2つのワークスペースで始まります。Sculpting ワークスペースに切り替えると自動でスカルプトモードになります。テンプレートは近道で、ワークスペースは + ボタンでいつでも追加できます。

ブラシ

  • ブラシカーソルの外側の輪はサイズ、内側の輪は強さ、色はブラシの種類を表します。
  • 既定は Draw ブラシで、頂点を表面から押し出します。Ctrl を押すと逆に、内側へ押し込みます。
  • ヘッダーの Size / Strength は、ショートカット F(サイズ)、Shift + F(強さ)で、左右にドラッグして調整できます(Shift で細かく、Ctrl で刻み)。これらは「最大値」で、タブレットでは筆圧で動的に下げられます。
  • Ctrl + Z でストロークを取り消せます。

ブラシの選択

  • ツールバーの上の4つがブラシ系のツールです。ヘッダーの幅広いボタンから、全ブラシの一覧が開きます。
  • 下部のアセットシェルフに、全ブラシアセットが並びます。Shift + Space でポップアップとして開き、名前を入力してすぐ選べます。
  • アセットとは、再利用できるようにマークされた、オブジェクト・コレクション・マテリアル・ブラシなどのデータのことです。アセットシステムは後のプロジェクトワークフローで詳しく扱います。

対称を保つ

  • ヘッダーで X Mirror を有効にします。
  • すでにスカルプトした後は Symmetrize が使えます。方向(Direction)を選んで実行すると、片側が削除され、選んだ方向からのミラーで置き換わります。
  • ミラーの中心や軸がずれている場合:オブジェクトモードで原点の位置と回転を調整します。例えば、3Dカーソルを目的の場所に置き(Shift + 右クリック、または Shift + S のスナップメニュー)、コンテキストメニューの Set Origin で原点をそこに合わせます。細かく動かすには、Options パネルで Affect Only Origins を有効にして、原点だけを動かします(作業後は必ず無効に戻すこと)。Bisect を有効にした Mirror モディファイアで、Symmetrize の結果をプレビューすることもできます(確認後は削除)。
  • スカルプトモードのミラーには、放射状、軸のロック、タイリングなど、さらに多くの機能があります。

全体の形を変える:Grab ブラシ

アセットシェルフで Grab を選びます。カーソルが黄色になりますが、黄色は「メッシュを動かす・変形する」ブラシの色です。クリックした時点でブラシの半径内にあった頂点だけを動かし、形を大きく変えるのに最適です。球を頭の形に変えるなどを試しましょう。

ジオメトリが足りなくなったら

スカルプトを続けるとメッシュが引き伸ばされ、頂点が足りなくなります。理想は頂点が均等に分布したメッシュです。これを取り戻す「リメッシュ」が2種類あります。形やメッシュの密度を確認するには、ヘッダーのオーバーレイの Geometry で Wireframe を有効にし、Opacity を 0.6 程度にすると見やすくなります。

ボクセルリメッシュ

  • R でグリッドを表示し、マウスを左右に動かして密度を調整(Shift で微調整)。左クリックまたは Enter で確定。Ctrl + R でリメッシュを実行。
  • ボクセル(体積のピクセル)を単位に、均等なメッシュを作り直します。つまり、メッシュの体積だけを見ます。例えば、重なる複数のオブジェクトを結合(Ctrl + J)してリメッシュすると、交差する部分や内側のジオメトリは削除され、全体がきれいにつながった1つのメッシュになります。
  • 注意:密度によっては近くの面同士(手の指など)がくっつくことがあります。また、閉じた体積でないメッシュはリメッシュで壊れます(すぐ分かるので取り消せます)。
  • Tip 最初は低い密度から始めて、大きな形に集中し、ディテールが必要になったら密度を上げていくのがよい流れです。

スムージング

リメッシュ後は表面がギザギザになりがちです。解決するSmooth ブラシは非常に重要で、ほぼ全てのブラシで Shift を押しながらストロークすると使えます(アセットシェルフや S でも)。サブディビジョンサーフェスに似た滑らかさで(解像度は増えません)、体積が縮みやすい点に注意。頂点間の距離を平均化する効果もあります。Smooth ブラシの Strength は、Shift で使う場合の全体のスムージング強度でもあります。

面を平らにする

頂点が多いほどスムーズの効果は弱くなります。大きな形を完全に平らにしたり削り取ったりするには、赤色系の次のブラシを使います。

  • Scrape:最もよく使う。Ctrl を押すと Fill の動作になり、平面化や形の単純化の制御がしやすい。
  • Fill:単独でも使え、くぼみや広い範囲の埋めに向く。
  • Flatten:削るのと埋めるのを同時に行い、頂点をブラシ中心に寄せる。弱い筆圧では、より柔らかく控えめに効く。

どのブラシでも状況を解決できることが多いので、最初は使いやすいものを選び、徐々に増やしましょう。

粘土を盛る:Clay と Clay Strips

初期のスカルプトで愛用される万能ブラシです。最初は荒々しく感じますが、形と体積を素早く盛れます(あとで少しスムージングが必要)。Clay Strips は四角く硬い減衰で、二次的な形の追加にも便利。Clay は柔らかく、スカルプトしながらメッシュを滑らかにするため、柔らかい有機的な形を作れます。どちらも筆圧の細かな制御が効果的で、Ctrl で引き算になります。

ダイナミックトポロジーと Snake Hook

頻繁に Ctrl + R でリメッシュするのは面倒です。また、Snake Hook のようなブラシは、1回のストロークで頂点が足りなくなりがちです。Snake Hook は Grab と違い、メッシュを少しずつ引き出し、ストロークの向きに回転して追従し、ストローク中に頂点を動的に拾ったり離したりします。

ヘッダーの Dyntopo を有効にする(確認ポップアップで Enable)と、スカルプト中にサーフェスがリメッシュされるようになります(メッシュ全体が三角形化)。利点は次のとおりです。

  • ブラシが常に均等なトポロジーの上で動作する
  • 手動でリメッシュする必要がない
  • スカルプトした面だけがリメッシュされる

体積ではなく表面をリメッシュ

  • Dyntopo の有効中は、スカルプトモード全体が特殊な状態になり、ボクセルリメッシュなど一部の機能は使えません(2つは排他的)。使えない機能があれば Dyntopo を無効にします。
  • 体積ではなく表面をリメッシュするため、平らで開いたメッシュ(厚みのないもの)に最適です。切り離された面同士を結合することはできません。
  • Grab など、Dyntopo でリメッシュできないブラシもあります。代わりに Pull が使えます。
  • 重要 Dyntopo はスケッチに最適ですが、頂点が多いと性能が落ちます。密度はできるだけ低く保ちましょう。

ダイナミック解像度

Dyntopo の有効中も、R で密度を変えられます(グリッドは三角形で表示)。固定ではなく、既定ではサーフェスにどれだけズームしているかに相対的です。ズームアウトすると、既存の表面の上でスカルプトした際に解像度が下がることがあります。挙動は Dyntopo ポップアップの Detailing で変更できます。

  • Relative(既定):画面上のサイズ(ピクセル)に相対的
  • Constant:ボクセルリメッシュのように一定で、Ctrl + R(Flood Fill)で、見えていてマスクされていない頂点全体をリメッシュできる
  • 解像度を下げたくない場合は、Refine Method を「Subdivide Collapse」から「Subdivide Edges」に変更する

表面を単純にリメッシュして滑らかにする Density ブラシもあります。

膨らませる:Inflate

他のブラシは頂点を一方向に押しますが、Inflate は表面から垂直に、全方向へ外側に押し出します。頭から角を引き出したあとに使うと有効で、仕上げに少しスムージングすると柔らかくなります。

シャープなディテール

細かい部分に鋭いクリース(溝)を入れるブラシには、Crease Polish、Crease Sharp、Draw Sharp、Pinch があります。最もよく使うのは Draw Sharp で、Draw に似ていますが、減衰がずっと鋭く、既定では向きが反転します。鋭い溝やしわを彫るのに便利です。Pinch と Crease は頂点を寄せる効果もあり、Dyntopo の有効中は表面もリメッシュします。ツールチップで詳細を確認してみましょう。ここで紹介したブラシで、スカルプト時間の約90%をカバーできます。

心得

  • まず基本の形とシルエットを作る。ディテールは後回し。
  • できるだけ低い解像度で作業する。段階的に解像度を上げ、ディテールは後に集中する。
  • 唯一の正しいスカルプトの方法はない。多くのブラシで目的の結果に届く。
  • うまくいかなくても続ける。スカルプトは反復で、時間の約80%はひどい見た目でも問題ない。

まとめ

スカルプトの基本ブラシ、2種類のリメッシュと一般的なブラシの併用、モデルの対称を作り保つ方法を学びました。新しい機能とブラシが多かったので、自由に試して慣れましょう。
