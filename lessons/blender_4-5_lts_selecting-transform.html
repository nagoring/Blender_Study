選択と変形

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Selecting & Transform

このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

ツールによる変形

  • Move:矢印を左ドラッグでその軸に移動。色付きの四角は平面上での拘束移動(青なら高さ不変でXY移動)。移動量は左上に表示されます。
  • Rotate:色付きの円弧が各軸の回転。白い円は画面基準の回転、内側の暗い部分はトラックボール回転(自由回転)。
  • Scale:Moveに似た操作で、白い円は均等スケール。
  • Transform:上の3つをまとめた1つのツール。

ショートカットによる変形

オブジェクトモードでも編集モードでも使えます。他のエディターでも共通なので重要です。

  • G=移動(Grab)、S=スケール、R=回転(R Rでトラックボール回転)
  • 続けて X / Y / Z を押すと軸に拘束。押し直すと軸を変更できます。
  • 左クリックで確定、右クリックまたは Esc でキャンセル。
  • Tip Shift を押しながら操作すると、より細かい刻みになります。

トランスフォームオリエンテーション

  1. 右上でMoveギズモを常時表示にします。
  2. 立方体をZ軸まわりに回転(R Z 45)し、オリエンテーションを Local に切り替えると、ギズモが立方体の向きに揃います。
  3. 値を0に戻すには、サイドバー(N)の項目にカーソルを置いて Backspace(3軸まとめてリセット)。
  4. 編集モードでは Local のままだとギズモが揃わないので、Normal に切り替えます。

(任意)単位系

None(内部はメートル法だが単位非表示)、Metric、Imperial の3種類があります。建築ビジュアライゼーションや3Dプリントでは実寸が役立ちます。このコースでは Metric + Separate Units を使います。設定手順:新しいBlenderを開き、Scene Properties › Units で設定してから、File › Defaults › Save Startup File で上書き保存します(ウィンドウ配置など他の変更も保存されます)。
