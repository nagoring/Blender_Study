メッシュの選択

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Mesh Selection

🎬 このレッスンの動画は原文ページで視聴できます。 原文ページを開く(動画付き)
このページは動画を補助する日本語の要点です。操作の流れは動画で確認してください。

メッシュの特定部分を選ぶのは、Blenderの作業で欠かせません。ショートカットが多いので、じっくり練習しましょう。メッシュは頂点・辺・面で構成されます。

選択モード

Tab で編集モードに入り、左上で選択モードを切り替えます。キーボードでは 1=頂点、2=辺、3=面。頂点を1つ選んで辺モードにすると選択が消え(辺は頂点2つで構成されるため)、辺を選んで頂点モードに戻すと2頂点が選択されています。面モードでは辺の選択は消えます。Shift で追加選択できます。

コンテキストメニューと細分化

右クリック(右クリック選択設定なら W)でコンテキストメニューが開き、内容は選択モードで変わります。Subdivide は選択範囲を細かく分割します(選択が必要)。

ループ選択

  • 頂点/辺ループ:辺モード(2)で Alt を押しながら、辺の向きに沿った辺を選択。
  • フェイスループ:面モードで、縦の辺を選ぶと横方向のループ、横の辺を選ぶと縦方向のループが選ばれます。Shift + Alt で追加。
  • 最短パス:面を選んだ後、Ctrl を押しながら別の面を選ぶと、最短経路でつないで選択。頂点/辺モードでも使えます。

選択ツール

  • 円選択(C):カーソルの円内を左クリックで選択。ホイールやテンキー +/- でサイズ変更。Shift で解除。使用中はビューを回せません。ツールバーの「Select Circle」は動作が異なるため、他の方法を推奨。
  • ボックス選択(B):範囲内を選択。ツールバーの「Select Box」も同様で、Shift で追加、Ctrl で解除。
  • 投げ縄(ツールバーのSelect Lasso):自由に描いた形の内側を選択。直線側を使うときれいに選べます。Shift で追加、Ctrl で解除。
  • ツールバーの選択方法はオブジェクトモードでも使えます。

拡大縮小と反転

  • Ctrl + テンキー +/-:選択範囲を広げる/狭める(テンキーがなければ Select › More/Less)。
  • Ctrl + I:選択の反転。小さい範囲を選んで反転する方が速いこともあります。

X線表示

Alt + Z でX線表示を切り替えると、裏側までまとめて選択できます。平行投影では分かりにくいので、ボタンの状態を確認しましょう。

まとめ

選択モード、コンテキストメニューでの細分化、ループ選択と最短パス、円・ボックス・投げ縄選択、More/Less と反転、X線表示を学びました。
