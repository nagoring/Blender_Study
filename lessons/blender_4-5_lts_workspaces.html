ワークスペース

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Workspaces

ワークスペースは、作業ごとにエディターを配置しておく「プリセット」です。

ワークスペースを作る

  • 初期は Layout(3Dビューポート、アウトライナー、プロパティ)。「Geometry Nodes」はLayoutに加えてジオメトリノードエディターとスプレッドシートが入っています。
  • 「Shading」タブを開くとEEVEEのシェーダーコンパイルが始まり、一時的に重くなることがあります。
  • タブが見切れたら MMB ドラッグかホイールで横にスクロールします。
  • 末端の追加アイコンから、プリセットまたは Duplicate Current(現在のコピー)で新規作成できます。複製すると「Layout.001」ができるので、ダブルクリックで「General」などに改名します。
  • タブを右クリックすると、並べ替え(Reorder to Front)・複製・削除・切り替えができます。

ワークスペースをカスタマイズする

  • エリアの境界にカーソルを置くと矢印に変わります。右クリックで Area Options(分割・結合・入れ替え)が開きます。
  • Vertical Split で3Dビューポートを2つに分けると、別々の視点から同じモデルを見られます。
  • 境界で Join Down などを選ぶと、隣のエリアと結合できます(例:右の3Dビューポートを下のタイムラインと結合)。
  • レイアウトを保存するには File › Defaults › Save Startup File。ただしこのコースでは標準の Layout を使います。
