レンダー設定

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Render Settings

レンダー設定、デノイズとは何か、ライトパスを変えるとレンダリング結果がどう変わるかを学びます。練習用に light_path_example.blend(原文ページ参照)を使います。

サンプリング

  • Noise Threshold(ノイズのしきい値)を設定すると、画像のノイズが一定量を下回ったときにレンダリングが止まります。
  • Noise Threshold を無効にして、Max/Min Samples を使うこともできます(Cycles の従来のレンダリング方法で、Noise Threshold が 0 に設定されます)。
  • Render タブでは、最大時間(秒)も設定できます。

Tip 一般的な目安として、サンプル数が多いほど画像は洗練されノイズが減りますが、最終画像のレンダリングにも時間がかかります。ディテールのレベルなど、芸術的な要件を意識して、ライトバウンスの数を減らしたり、シーンを簡略化・最適化したりすれば、レンダリング時間を減らせます。

デノイズ

画像のほとんどのノイズを除去する優れた機能です。何千もの画像を分析してノイズを検出するよう、機械学習(AI)で訓練されたアルゴリズムです。欠点もあります。

  • サンプル数が少ないと、にじんでぼやけた結果になる。
  • サンプル数が不足すると、アニメーションのレンダリングでちらつく(「時間的不安定性」)。
  • 十分なサンプル数でも、望ましくない形で、画像にわずかに影響することがある。

Tip Passes を Albedo + Normal に設定すると、デノイザーにより多くの情報を与え、ノイズをうまく除去できます。Prefilter と Quality を上げると、レンダリングは遅くなります。デノイズは、レンダリング後ではなく、Denoise ノードでコンポジット中に行うこともできます。Light と Advanced タブは扱いません。デノイズの有効化は救世主になり、芸術的にも自由にしてくれます。設定を試してみましょう。

ライトパス

ライトパスは、特定のシェーディング要素の光線(経路)と、そのバウンス回数と考えられます。

  • Diffuse:色(アルベド)情報のバウンス数。間接ディフューズ(バウンスライティング)や、サブサーフェススキャッタリングのオブジェクトを含む。
  • Glossy:反射するオブジェクトを含むバウンス数。
  • Transmission:ガラスなどのオブジェクトのバウンス数。
  • Volume:煙や雲などのボリューム散乱のバウンス数。
  • Transparent:透明なオブジェクトを解決するバウンス数。

バウンスを増やすとパフォーマンスに影響し、レンダリング時間が増えます。各ライトパスのバウンスを増減して、結果への影響を確認しましょう。

  • Diffuse のバウンスが多いほど、画像は明るくなります。0 にすると、拡散のバウンスライティングが完全になくなり、暗い画像になります。
  • Glossy のバウンスが多いほど、2つの反射する球が正しく表示されます。
  • Transmission と Transparent のバウンスを増やすと、画像が整い、平面の黒い部分が消えます。Transmission を 5 にすると黒い部分がすべて消えます(平面が5枚あるため)。
  • Volume のバウンスを増やすと、壁の緑の色が、ボリューム散乱に影響します。

クランプとコースティクス

Clamping は、直接または間接のバウンスの「ファイヤーフライ」(白い光点)を除去または減らします。既定値で、ほとんどの場合問題ありません。Caustics は、さらにリアリティを加えます。Reflective は、反射面で光が跳ね返る効果です(例:向かいの家の窓に当たった太陽光が、自分の部屋を照らす)。Refractive は、Glossy ではなく Transmission を使ってコースティクスを作ります。芸術的なシーンで使えるかもしれない、Fast GI(グローバルイルミネーションの近似)も確認しましょう。

その他のタブ

  • Volume:ボリュームの品質設定で、ディテールを上げられる。
  • Curves:髪や草のレンダリング。高解像度のカーブか、簡単なリボンか。
  • Simplify:Subdivision Surface やパーティクルシステムのオブジェクトの、最大ディテール(ビューポートと最終レンダリング別)を調整。テクスチャやボリュームの解像度も制限できる。
  • Motion Blur:速く動くオブジェクトにブラーを加える。
  • Film:ピクセルフィルターの変更と、World の背景をアルファにする設定。
  • Performance:Blender の技術的な側面の設定。
  • Bake:テクスチャのベイク(色、粗さ、ノーマルなど、ディテールを別のテクスチャに「記録」する)。
  • Grease Pencil と Freestyle。

マニュアルの Reduce Noise のページも参照しましょう。トラブルシューティングには Error Message のページを参照。

まとめ

サンプルがレンダリングに与える影響、ライトパスが画像に与える視覚的な影響、画像の黒い部分は、特定のライトパスのバウンスがもっと必要というサインかもしれない、ということを学びました。
