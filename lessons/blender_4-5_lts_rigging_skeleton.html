スケルトンの作成

Blender Studio「Blender Fundamentals 4.5 LTS」の無料レッスンを、日本語で要点をまとめた非公式の学習ガイドです(逐語訳ではありません)。原文: Creating a Skeleton

キャラクター「Sky」にリグを付けながら、重要な基本概念を学びます。最初はアーマチュアです(練習用ファイル:sky_01_blank.blend、原文ページ参照)。

アーマチュアオブジェクト

キャラクターには骨格が必要です。Armature オブジェクトは、ボーンの集まりです。Shift + A › Armature で追加し、F2 で「RIG-Sky」と名付けます(接頭辞は、検索ボックスで見つけやすくするためです)。メッシュと同様に編集モードで、ボーンの押し出し・複製・変形ができます。基本的な左半身の骨格を作ります。

  • 背骨:Spine1/2/3 → Neck → Head
  • 左脚:Thigh.L → Knee.L → Foot.L → Toes.L
  • 左腕:Shoulder.L → Upperarm.L → Forearm.L → Hand.L
  • 左指:Fingers1/2/3.L、Thumb1/2/3.L
重要 Ctrl + R でボーンのロールをジオメトリに合わせます。例えば、肘のボーンは、肘が曲がる向きに合わせます。Shift + N(Recalculate Roll)も使えます。

手のヒント:詳細なキャラクターなら、中手骨のボーンも入れましょう。手の形を作るのに重要です。握りこぶしを作るには、指を特定の比率でモデリングする必要があります。比率が合わないときは、モデリングの調整が必要です。

ポーズモードと編集モード

  • ポーズモード:リグをポーズさせ、アニメーションさせます。Alt + G / R / S で、いつでも初期状態にリセットできます。
  • 編集モード:ボーンの追加、削除、親子付け、レストポーズの定義をします。アニメーションはできず、変更をリセットするには Ctrl + Z しかありません。

ペアレント:ボーン

  1. 編集モードで、子にするボーンを先に選ぶ。
  2. 親にするボーンを最後に選び、アクティブにする。
  3. Ctrl + P › Keep Offset で、選択したボーンをアクティブなボーンの子にします。Connected を選ぶと、子が親にスナップして接続されます。

必要なペアレントは3つです:Shoulder.L → Spine3、Thigh.L → Spine1、Thumb1.L → Hand.L。ボーンのペアレントは、編集モードでのみ行えます。

対称

時間を節約するために Symmetrize を使います。ボーンに .L / .R などの接尾辞を付ける必要があります。ボーンを選び、Armature › Symmetrize を実行すると、反対側のボーンが作られます。編集モードの X-Axis Mirror も有効にすると、変形がミラーされます(ポーズモードにも同じオプションがありますが、別設定です)。ミラーされない操作もあり、ボーン名の変更はその一つです。

ショートカットと設定(任意)

  • F2 で名前変更。見苦しい「.001」を避けましょう。
  • Alt + MMB で、平行投影のビューにスナップします。
  • 既定のキーマップのみ:「Grave Accent / Tilde Action」を「Navigate」にすると、` でビューのパイメニューが開きます。「Region Toggle Pie」を有効にすると、N でサイドバー以外も切り替えられます。X-Axis Mirror には、右クリック › Assign Shortcut で、Alt + X などを割り当てられます。, は「Orientation」パイ(変形の回転軸)、. は「Pivot Point」パイ(変形のピボット)です。

ペアレント:オブジェクト

Sky をシーンのどこにでも簡単に移動でき、拡大縮小もできるように、メッシュをアーマチュアの子にします。すべてのメッシュオブジェクトを選び、アーマチュアを最後に選んで Ctrl + P › Object (Keep Transform)。以後、アーマチュアを動かせば、キャラクター全体が追従します。

トランスフォームのロック

誤ってオブジェクトを動かすと、ボーンを誤った位置に追加するなどの問題が起きます。リグ以外のオブジェクトをロックしましょう。Alt + H ですべて再表示し、すべてのメッシュを選び、N › Item › Transform の鍵アイコンを、Alt を押しながらドラッグしてなぞります(Alt で、選択中のすべてに適用されます)。完成ファイル:sky_02_armature.blend(原文ページ参照)。

まとめ

アーマチュアと基本的な骨格の作り方、対称編集による時間の節約、キャラクターのオブジェクトをアーマチュアにペアレントする方法、トランスフォームのロックを学びました。
